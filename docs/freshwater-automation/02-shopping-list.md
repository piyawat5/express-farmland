# 🛒 รายการของ — เฟส 0 + เฟส 1

> ราคาประมาณการ ก.ย. 2026 (Shopee/Lazada/ร้านวัสดุ) อาจคลาดเคลื่อน ±30%
> คำที่อยู่ใน `กล่องแบบนี้` = คำค้นหา ก๊อปไปวางได้เลย · ไม่เข้าใจคำไหนดู [01-glossary.md](./01-glossary.md)

| ปุ่มกดที่ต้องบัดกรี (ขาเป็นแผ่นโลหะเล็ก ๆ) | ยังบัดกรีไม่เป็น — เลือกแบบขันสกรู |
