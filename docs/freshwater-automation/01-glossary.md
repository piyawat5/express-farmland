# 📖 ศัพท์ช่าง / IoT + ชื่อที่ใช้ค้นหา

> อ่านเมื่อเจอคำไม่รู้จัก · **คำค้น** = พิมพ์ใน Shopee / Lazada / Google ได้เลย
> ร้านไทยที่ขายอุปกรณ์ Arduino/ESP32 มีคนตอบคำถามได้: ThaiEasyElec, Arduitronics, Cybertice (ราคาอาจสูงกว่าร้านทั่วไปใน Shopee เล็กน้อย แต่ของปลอมน้อยกว่า)

## ก. สมองและการเขียนโปรแกรม

### ESP32 DevKit V1
- **คืออะไร:** คอมพิวเตอร์จิ๋วบนบอร์ดขนาดนิ้วโป้ง มี WiFi ในตัว สั่งเปิด-ปิดอุปกรณ์และอ่านเซนเซอร์ได้ = "สมอง" ของระบบ
- **คำค้น:** `ESP32 DevKit V1 30 ขา` · `ESP32 ESP-WROOM-32 30pin` · `ESP32 Type-C CH340C 30pin`
- **ต้องดู:** ชิป **ESP-WROOM-32**, **30 ขา** (มีแบบ 38 ขาด้วย ขาเรียงไม่เหมือนกัน — เอกสารชุดนี้ใช้ 30 ขา), หัว USB แบบ **Type-C** ใช้สะดวกกว่า Micro USB
- **ห้ามซื้อ:** ESP32-**C3** / **S2** / **S3** mini (ขาไม่ตรงกับเอกสารนี้), ESP8266 / NodeMCU (รุ่นเก่า ขาน้อย)

### บอร์ดขยายขา (Terminal adapter)
- **คืออะไร:** ฐานที่เสียบ ESP32 ลงไป แล้วทุกขามี **ขั้วสกรู** ให้ขันสายไฟ — **ไม่ต้องบัดกรีเลย**
- **คำค้น:** `บอร์ดขยาย ESP32 30 ขา เทอร์มินอล` · `ESP32 30P terminal adapter` · `ESP32 expansion board 30pin`
- **ต้องดู:** ต้องเป็น **30 ขาให้ตรงกับบอร์ด**

### สาย USB แบบ Data
- สายชาร์จมือถือราคาถูกหลายเส้น **มีแต่สายไฟ ไม่มีสายข้อมูล** → เสียบแล้วคอมไม่เห็นบอร์ด (ปัญหามือใหม่อันดับ 1)
- **คำค้น:** `สาย USB Type-C data sync` — หรือใช้สายที่เคยโอนไฟล์มือถือเข้าคอมได้

### ไดรเวอร์ CH340 / CP2102
- ชิปแปลง USB บนบอร์ด ESP32 — Windows บางเครื่องต้องลงไดรเวอร์ก่อนถึงจะมองเห็นบอร์ด
- ดูตัวชิปเล็ก ๆ ใกล้หัว USB ว่าเขียน CH340 หรือ CP2102 → ค้น `CH340 driver` (เว็บ wch.cn) หรือ `CP210x driver` (เว็บ silabs.com)

### Arduino IDE 2
- **คืออะไร:** โปรแกรมฟรีบนคอม ใช้เขียนโค้ดแล้ว "อัปโหลด" ลง ESP32 · ดาวน์โหลดที่ arduino.cc
- **Sketch** = ไฟล์โค้ด 1 ชุด · **อัปโหลด** = ส่งโค้ดลงบอร์ด · **Serial Monitor** = หน้าต่างดูข้อความที่บอร์ดพิมพ์ออกมา (ใช้หาปัญหา)
- ภาษาที่ใช้ = **C++ แบบ Arduino** (อ่านง่ายกว่าที่คิด และ Claude เขียนให้ได้)

### GPIO / ขา
- ขาบนบอร์ดที่ใช้ "สั่ง" (output เช่น เปิดรีเลย์) หรือ "อ่าน" (input เช่น ลูกลอย/ปุ่ม) — เรียกด้วยเลข เช่น GPIO16 (บนบอร์ดมักพิมพ์ว่า D16 หรือ 16)
- **INPUT_PULLUP** = ตั้งให้ขาอ่านค่าเป็น "สูง" ตอนไม่มีอะไรต่อ → ต่อปุ่ม/ลูกลอยระหว่างขานั้นกับ GND ได้เลย ไม่ต้องใส่ตัวต้านทานเพิ่ม
- **GND** = ขั้วลบ/กราวด์ ทุกอุปกรณ์ในกล่องต้องใช้ GND ร่วมกัน

### WiFi 2.4 GHz
- ESP32 ต่อได้ **เฉพาะ WiFi 2.4 GHz** (ต่อ 5 GHz ไม่ได้) — เราเตอร์บ้านส่วนใหญ่มีทั้งสองคลื่น ถ้าตั้งชื่อ WiFi รวมกันไว้มักใช้ได้เลย

### mDNS (ชื่อ farm-water.local)
- ชื่อเล่นให้พิมพ์ในเบราว์เซอร์มือถือแทนเลข IP · iPhone ใช้ได้ Android บางรุ่นใช้ไม่ได้ → ใช้เลข IP ที่โชว์ใน Serial Monitor แทน

### NVS / NTP
- **NVS** = หน่วยความจำถาวรใน ESP32 (ถอดปลั๊กแล้วไม่หาย) ใช้จำว่าถังไหนเพิ่งเติมประปาเมื่อไร
- **NTP** = ดึงเวลาจริงจากอินเทอร์เน็ต (ESP32 ไม่มีถ่านนาฬิกา)

## ข. ไฟฟ้า

### รีเลย์ (Relay) / โมดูลรีเลย์
- **คืออะไร:** สวิตช์ไฟที่ ESP32 สั่งเปิด-ปิดได้ (ได้ยินเสียง "แกร๊ก") — ESP32 จ่ายไฟให้ปั๊มเองไม่ได้ ต้องสั่งผ่านรีเลย์
- **ช่อง (channel)** = จำนวนสวิตช์บนแผง · เราใช้ **8 ช่อง** (ใช้จริง 3 เหลือเผื่อเฟสหน้า)
- **ขั้วฝั่งสวิตช์ 3 ขั้วต่อช่อง:** `COM` (ขาเข้าร่วม) · `NO` (Normally Open = ปกติตัดวงจร สั่งแล้วต่อ ← **ใช้อันนี้**) · `NC` (ปกติต่อ สั่งแล้วตัด — ไม่ใช้)
- **High/Low trigger:** แผงบางรุ่นมีจัมเปอร์ (ตัวครอบพลาสติกเล็ก ๆ) ให้เลือก H หรือ L → **ตั้งเป็น H** เพราะ ESP32 ส่งไฟแค่ 3.3V (แผงที่เป็น Low trigger อย่างเดียว ต่อกับ ESP32 แล้วรีเลย์มักค้าง ไม่ยอมดับ)
- **Optocoupler** = ชิปกั้นไฟระหว่างฝั่งสมองกับฝั่งสวิตช์ ช่วยกันสัญญาณรบกวน
- **คำค้น:** `โมดูลรีเลย์ 8 ช่อง 5V High Low trigger optocoupler` · `8 channel relay module 5V high low level trigger`

### อะแดปเตอร์ 12V (Switching adapter)
- หม้อแปลงเสียบปลั๊กบ้าน ได้ไฟ 12V ออกมาทางหัวแจ็ค — **ส่วนที่เป็นไฟบ้าน 220V ปิดมิดชิดอยู่ในตัว** เราไม่ต้องยุ่งเลย
- **A (แอมป์)** = จ่ายกระแสได้สูงสุดเท่าไร · ปั๊ม DC40 กินราว 1–1.6A และเราเปิดทีละตัว → ใช้ **12V 5A** เผื่อเหลือ
- **คำค้น:** `อะแดปเตอร์ 12V 5A หัว 5.5x2.1` (แบบเดียวกับที่ใช้กับกล้องวงจรปิด/ไฟเส้น LED)

### แจ็ค DC ตัวเมียแบบขั้วสกรู
- หัวเสียบรับอะแดปเตอร์ แล้วมีขั้วสกรู + / − ให้ขันสาย · **คำค้น:** `แจ็ค DC ตัวเมีย 5.5x2.1 เทอร์มินอล`

### Step-down / Buck converter (ตัวลดแรงดัน)
- แปลงไฟ 12V → 5V ไปเลี้ยง ESP32 และแผงรีเลย์
- **แนะนำ Mini560 แบบ fix 5V** (ไม่ต้องหมุนปรับ) · **คำค้น:** `Mini560 step down 5V` · `DC-DC step down 12V to 5V 3A`
- ถ้าได้แบบ LM2596 (มีปุ่มหมุนสีฟ้า) ต้องใช้มัลติมิเตอร์วัดแล้วหมุนให้ได้ 5.0V **ก่อน** ต่อกับ ESP32 ไม่งั้นบอร์ดไหม้

### ฟิวส์ + กระบอกฟิวส์ (Inline fuse holder)
- ถ้าสายลัดวงจร ฟิวส์จะขาดก่อน สายไม่ไหม้ · **คำค้น:** `กระบอกฟิวส์ รถยนต์ แบบเสียบ` + `ฟิวส์เสียบ 5A` (ฟิวส์รถยนต์ใช้กับไฟ 12V ได้)

### ขั้วต่อสาย Wago 221
- ตัวหนีบต่อสายแบบ "ยกคันโยก → เสียบสาย → กดคันโยก" แทนการบิดสาย/พันเทป/บัดกรี แน่นและถอดได้
- **คำค้น:** `Wago 221-412` (2 ช่อง) · `Wago 221-413` (3 ช่อง) · `Wago 221-415` (5 ช่อง — ใช้ทำ "บัส" รวมสาย +12V และ GND)

### สายไฟ: sq.mm / VCT
- **sq.mm (ตร.มม.)** = ขนาดทองแดง ยิ่งมากยิ่งรับกระแสได้มาก · สายปั๊ม: **2×1.0 sq.mm** · สายลูกลอย/ปุ่ม: **2×0.5 sq.mm** ก็พอ
- **VCT** = สายอ่อนหุ้มฉนวน 2 ชั้น ทนแดดทนน้ำดีกว่า · **คำค้น:** `สายไฟ VCT 2x1` · `สายไฟอ่อน 2 แกน 0.5`
- **ทางลัด:** ถ้าปั๊มมาพร้อมหัวแจ็ค DC → ใช้ `สายต่อยาว DC 12V กล้องวงจรปิด 5 เมตร` เสียบต่อได้เลย ไม่ต้องตัดต่อสาย

### ท่อหดมีกาวใน (Heat shrink with glue)
- ท่อพลาสติกสวมทับรอยต่อสาย ใช้ไดร์เป่าผม/ไฟแช็กลนให้หดรัด + กาวข้างในกันน้ำเข้า · **คำค้น:** `ท่อหด มีกาวใน`

### กล่องกันน้ำ IP65 + เคเบิ้ลแกลนด์
- **IP65** = กันฝุ่น + กันน้ำฉีด (แต่ห้ามแช่น้ำ) · **คำค้น:** `กล่องกันน้ำ IP65 พลาสติก 20x15x10`
- **เคเบิ้ลแกลนด์ (Cable gland)** = ตัวร้อยสายเข้ากล่อง ขันแล้วบีบรอบสายกันน้ำเข้า · **คำค้น:** `เคเบิ้ลแกลนด์ PG7` (สายโต 3–6 มม.) / `PG9` (4–8 มม.)

### ปุ่มกด 22 มม. ขั้วสกรู (Momentary push button)
- **Momentary / กดติดปล่อยดับ** = กดแล้วเด้งกลับ ← **ใช้อันนี้** · (Latching / กดติดกดดับ = ค้างสถานะ ไม่ใช้)
- **ขนาด 22 มม. แบบอุตสาหกรรม (รุ่น LA38)** มี **ขั้วสกรู** ให้ขันสาย — ไม่ต้องบัดกรี (ปุ่ม 16 มม. ส่วนใหญ่ต้องบัดกรี)
- ด้านหลังปุ่มมีขั้ว 2 คู่: **NO** (มักเขียน 3–4) ← ใช้คู่นี้ · NC (มักเขียน 1–2) ไม่ใช้ — ไม่แน่ใจให้ใช้มัลติมิเตอร์โหมดปี๊บ: คู่ที่ปี๊บ**เฉพาะตอนกด** = NO
- **คำค้น:** `สวิตช์กด 22mm LA38 กดติดปล่อยดับ` · `push button 22mm LA38-11BN` · เลือกสีเขียว / น้ำเงิน / แดง
- ปุ่มแบบนี้ไม่กันน้ำ 100% → ติดบนฝากล่องที่อยู่ใต้หลังคา ไม่โดนฝนตรง ๆ

### บัซเซอร์ (Buzzer)
- ลำโพงเสียงปี๊บ · **Active** = จ่ายไฟแล้วดังเลย ← ใช้อันนี้ · (Passive ต้องส่งความถี่ให้ ยุ่งกว่า)
- **คำค้น:** `active buzzer module 3 ขา` (มีขา VCC / GND / I/O)

### มัลติมิเตอร์ (Multimeter)
- เครื่องวัดไฟ — **จำเป็นมาก** ใช้ 2 โหมด:
  - **โหมดเสียงปี๊บ (continuity — สัญลักษณ์รูปคลื่นเสียง):** แตะ 2 ปลาย ถ้าปี๊บ = ต่อถึงกัน (ใช้เช็คลูกลอย/ปุ่ม/สายขาด)
  - **DCV (ตัว V ที่มีขีดตรงด้านบน):** วัดแรงดันไฟ DC เช่น เช็คว่า step-down ออก 5V จริง
- **คำค้น:** `มัลติมิเตอร์ดิจิตอล` (รุ่น 250–400฿ พอ)

## ค. น้ำ ท่อ และเซนเซอร์

### ปั๊มน้ำ DC 12V จุ่มน้ำ ไร้แปรงถ่าน (Brushless) — ตระกูล DC40 — **ใช้เป็นปั๊ม P3 (ถัง 3 → ถังกรอง)**
- **คืออะไร:** ปั๊มจุ่มในถัง ใช้ไฟ 12V (ปลอดภัย ไม่ช็อต) เงียบ ทน ใช้กันมากในตู้ปลา/น้ำพุ
- ใช้เฉพาะขาที่น้ำไหลเองไม่ได้ (ถัง 3 ที่วางบนพื้น ต่ำกว่าผิวน้ำถังกรอง) · ถ้าโซลินอยด์ V1/V2 ใช้กับหัวน้ำต่ำไม่ได้ ก็ใช้ปั๊มรุ่นนี้แทนได้
- **อ่านชื่อรุ่น:** `DC40-1250` → **12** = 12V, **50** = ส่งน้ำสูงได้ 5 ม. (1230 = 3 ม., 1240 = 4 ม.) — ใช้ **1240 หรือ 1250**
- **คำค้น:** `ปั๊มน้ำ DC40-1250` · `ปั๊มน้ำ DC 12V brushless จุ่ม` · `DC40A-1250 12V`
- **ต้องดู:** 12V DC, brushless, จุ่มน้ำได้ (IP68), ขนาดหางปลาไหลขาออก (จดไว้ ใช้ซื้อสายยาง), มาพร้อมหัวแจ็ค DC หรือสายเปลือย
- **ห้าม:** ปล่อยเดินตัวเปล่าตอนไม่มีน้ำ (แกน/ลูกปืนเซรามิกข้างในพัง)
- **ทำไมไม่ใช้ปั๊มไดโว่ 220V:** ต้องต่อไฟบ้านผ่านรีเลย์ อันตรายสำหรับมือใหม่ + แรงเกินงานนี้มาก

### ลูกลอยไฟฟ้า (Float switch) รุ่น ZP4510
- **คืออะไร:** ลูกลอยพลาสติกเลื่อนขึ้นลงบนแกน ข้างในมีแม่เหล็ก + สวิตช์ → น้ำถึงลูกลอย = วงจร "ต่อ" หรือ "ตัด" ใช้บอกว่า "น้ำถึงระดับนี้แล้ว"
- **แนวตั้ง (vertical)** = แกนตั้ง ← **ใช้อันนี้** · (แนวนอน = ต้องเจาะผนังถังใต้ระดับน้ำ เสี่ยงรั่ว ไม่ใช้)
- **กลับหัวลูกลอยได้:** ถอดคลิปล่างแล้วกลับด้านลูกลอย = สลับว่าน้ำขึ้นแล้ว "ต่อ" หรือ "ตัด" (ใช้ทำ fail-safe)
- **คำค้น:** `ลูกลอยไฟฟ้า แนวตั้ง ZP4510` · `float switch ZP4510` · `สวิตช์ลูกลอย ตู้ปลา แนวตั้ง PP`
- **ต้องดู:** วัสดุ PP, เกลียว M10, ยาว ~45 มม., มีน็อตแถม
- **ระวัง:** ทนกระแสได้แค่ราว 0.5A → ต่อเข้า ESP32 เท่านั้น **ห้ามใช้ตัดไฟปั๊มตรง ๆ**

### เสาเซนเซอร์ (ออกแบบเองในโปรเจกต์นี้)
- ท่อ PVC 6 หุนห้อยลงในถัง ปลายล่างปิดด้วยฝาครอบที่เจาะรูใส่ลูกลอย สายลูกลอยวิ่งขึ้นในท่อ → ตั้งระดับได้ด้วยการเลื่อนท่อขึ้นลง **ไม่ต้องเจาะถังใต้น้ำ** (วิธีทำใน 05)

### เซนเซอร์ระดับน้ำแบบแสง (Optical) — ใช้เฟส 5
- ไม่มีชิ้นส่วนขยับ ไม่ติดตะกอน/หอย แม่นกว่าลูกลอย · **คำค้น:** `optical liquid level sensor` · `FS-IR02`

### อัลตราโซนิกกันน้ำ — ใช้เฟส 2
- วัดระยะถึงผิวน้ำด้วยคลื่นเสียง (ไม่แตะน้ำ) → รู้ว่าถังเหลือกี่ % และรู้ว่ามีคนเพิ่งเติมน้ำ
- **คำค้น:** `JSN-SR04T` (ถูก แต่ต้องติดสูงจากน้ำ ≥ 25 ซม.) · `A02YYUW` (แพงกว่า ใกล้น้ำได้ 3 ซม. ทนชื้นกว่า)

### ปั๊มรีดสาย (Peristaltic pump) — ใช้เฟส 3
- ปั๊มที่บีบสายยางเป็นจังหวะ ปล่อยของเหลวได้แม่นระดับมิลลิลิตร ใช้โดสสารละลายโซดา · **คำค้น:** `peristaltic pump 12V` · `ปั๊มรีดสาย 12V` · `Kamoer NKP 12V`

### โซลินอยด์วาล์ว (Solenoid valve) — **ใช้เป็นวาล์ว V1, V2 (ถัง 1/2 → ถัง 3)**
- **คืออะไร:** ก๊อกน้ำไฟฟ้า ข้างในมีขดลวด (คอยล์) จ่ายไฟ 12V แล้ววาล์วเปิด ตัดไฟแล้วปิด
- มี 2 แบบที่ต้องแยกให้ออก — **ซื้อผิดแบบ = ใช้ไม่ได้เลย:**
  - **Pilot operated (แบบนำร่อง)** = ต้องมีแรงดันน้ำดันถึงจะเปิดได้ (ตัวพลาสติกขาว/ดำ 80–150฿ ที่สเปกเขียน `0.02–0.8 MPa`) → **ใช้กับถังที่น้ำไหลเองไม่ได้** แต่ใช้กับ **ท่อประปา** ได้ (เฟส 2 ถ้าอยากให้ระบบเติมประปาลงถัง 1/2 เอง)
  - **Zero pressure / 0 bar (แบบเปิดได้ที่แรงดันศูนย์)** = ← **ใช้อันนี้** · สเปกต้องเขียนว่า `0 bar` หรือ `0–10 kgf/cm²` หรือ `zero pressure` (แรงดันต่ำสุดเป็นศูนย์)
- **รุ่นที่แนะนำ:** `2W-160-15` → **2W** = วาล์ว 2 ทาง, **160** = รูใน 16 มม., **15** = ขนาด DN15 = **4 หุน (1/2 นิ้ว)** · ตัวทองเหลือง เกลียวใน 4 หุนทั้ง 2 ข้าง
- **คำค้น:** `โซลินอยด์วาล์ว 2W-160-15 12VDC NC` · `solenoid valve 2W160-15 DC12V normally closed`
- **ต้องดู 4 อย่าง:** (1) ไฟคอยล์ **DC 12V** (ไม่ใช่ AC220V / DC24V) (2) **NC (Normally Closed)** = ไฟดับแล้วปิดเอง (3) แรงดันต่ำสุด **0** (4) ขนาด **4 หุน**
- **ลูกศรบนตัววาล์ว** = ทิศที่น้ำต้องไหล — ใส่กลับด้านแล้วรั่ว/ไม่ปิด
- วาล์วแบบนี้กินไฟ ~1–1.5A ตอนเปิด และคอยล์อุ่นขึ้นถ้าเปิดนาน — ปกติ (เราเปิดแค่ครั้งละไม่กี่นาที)
- **ข้อจำกัด:** ข้างในมีแผ่นยางและรูเล็ก ๆ → เศษตะกอนทำให้ปิดไม่สนิทได้ ต้องมี **วายสเตรนเนอร์** กรองก่อนเข้าวาล์ว และ **ทดสอบกับหัวน้ำต่ำก่อนเจาะถังจริง** (05 ข้อ 1)

### ปลั๊กคอยล์ DIN + ไดโอด 1N4007 (กันไฟกระชากจากวาล์ว)
- **ปลั๊กคอยล์ DIN:** ขั้วสี่เหลี่ยมที่เสียบบนหัววาล์ว เปิดฝาได้ ข้างในมีขั้วสกรูให้ขันสาย (มักแถมมากับวาล์ว)
- **ไดโอด 1N4007:** ชิ้นส่วนเล็กสีดำมีแถบสีเงิน 1 ด้าน · ตอนตัดไฟวาล์ว ขดลวดจะดีดไฟกระชากกลับ → อาจทำให้หน้าสัมผัสรีเลย์ไหม้ หรือ **ESP32 รีสตาร์ตเอง** · ไดโอดคร่อมขั้วคอยล์จะดูดไฟกระชากนั้นทิ้ง
- **วิธีใส่:** ขันขาไดโอดเข้าขั้วสกรูในปลั๊ก DIN คู่กับสายไฟ — **ด้านที่มีแถบสีเงินอยู่ฝั่งสาย + (แดง)** · ใส่กลับด้าน = ลัดวงจร ฟิวส์ขาด (ฟิวส์ช่วยไว้ ไม่มีอะไรไหม้)
- **คำค้น:** `ไดโอด 1N4007` (ซื้อเป็นแพ็ก 10–20 ตัว ถูกมาก)

### มอเตอร์บอลวาล์ว (Motorized ball valve) — พิจารณาแล้ว **ไม่เลือก**
- วาล์วที่ใช้มอเตอร์หมุนลูกบอลเปิด-ปิด เปิดได้ที่แรงดันศูนย์และรูกว้าง แต่ **ไฟดับแล้วค้างอยู่ตำแหน่งเดิม** (ถ้าไฟดับตอนเปิดอยู่ น้ำไหลไม่หยุด) → ขัดกับหลักไฟดับต้องปิด · คำค้นเผื่ออนาคต: `motorized ball valve 12V CR02` (มีรุ่นที่มีตัวเก็บประจุปิดเองตอนไฟดับ แต่แพงกว่า)

### หัวน้ำ / ความสูงต่าง (Head)
- แรงที่ทำให้น้ำไหลเองมาจาก **ผิวน้ำต้นทางสูงกว่าปลายทาง** ยิ่งต่างมากยิ่งไหลแรง · ต่างน้อย (10–30 ซม.) ก็ไหลได้แต่ช้า
- น้ำไหลเองได้ **ลงอย่างเดียว** ถ้าปลายทางสูงกว่าต้องใช้ปั๊ม

### บอลวาล์ว (มือ) · วายสเตรนเนอร์ · นิปเปิ้ล · เทปพันเกลียว
- **บอลวาล์ว (Ball valve):** ก๊อกหมุน 90° เปิด-ปิดด้วยมือ ใส่ไว้ติดถัง 1/2 ใช้ปิดตอนซ่อมวาล์ว หรือปิดฉุกเฉินถ้าโซลินอยด์ค้าง · **คำค้น:** `บอลวาล์ว PVC 4 หุน เกลียว` หรือ `บอลวาล์วทองเหลือง 4 หุน`
- **วายสเตรนเนอร์ (Y-strainer):** ข้อต่อรูปตัว Y มีตะแกรงข้างใน กรองเศษก่อนเข้าโซลินอยด์ ถอดตะแกรงออกมาล้างได้ · **คำค้น:** `วายสเตรนเนอร์ ทองเหลือง 4 หุน` · `Y strainer 1/2` · ลูกศรบนตัวต้องชี้ไปทางวาล์ว
- **นิปเปิ้ล (Hex nipple):** ข้อต่อสั้น ๆ เกลียวนอกทั้ง 2 ข้าง ใช้ต่อของที่เป็นเกลียวในเข้าด้วยกัน (บอลวาล์ว ↔ วาย ↔ โซลินอยด์) · **คำค้น:** `นิปเปิ้ลทองเหลือง 4 หุน`
- **หางปลาไหลเกลียวนอก:** ข้างหนึ่งเกลียวนอกขันเข้าวาล์ว อีกข้างเป็นหางปลาไหลสวมสายยาง · **คำค้น:** `หางปลาไหล เกลียวนอก 4 หุน`
- **เทปพันเกลียว (PTFE / เทปขาว):** พันเกลียวนอกตามเข็มนาฬิกา 5–8 รอบก่อนขัน กันรั่ว · **คำค้น:** `เทปพันเกลียว`
- 💡 **เคล็ดลับ:** เอาผังใน [03 ข้อ 6.2](./03-wiring.md) ไปให้ร้านวัสดุดู แล้วบอกว่า "ขอชุดต่อจากข้อต่อถัง → บอลวาล์ว → วาย → โซลินอยด์ → หางปลาไหล ขนาด 4 หุนทั้งหมด" ร้านจะจัดข้อต่อให้ครบ

### ฐานวางถัง
- **บล็อกคอนกรีต (อิฐบล็อก):** วางเรียงเต็มแผ่นบนพื้นเรียบ ซ้อน 2–3 ชั้น · ห้ามใช้อิฐมอญหัก ๆ ซ้อนกันสูง
- **ขาตั้งถังน้ำสำเร็จรูป:** **คำค้น:** `ขาตั้งถังน้ำ เหล็ก` · `แท่นวางถังน้ำ`
- ใช้ **ระดับน้ำ (ที่วัดระดับ / ตลับฟองอากาศ)** หรือแอประดับน้ำในมือถือ เช็คว่าฐานไม่เอียง

### หุน (ขนาดท่อ)
- ร้านวัสดุไทยเรียกขนาดท่อเป็น "หุน" · **4 หุน = 1/2 นิ้ว** · **6 หุน = 3/4 นิ้ว** · 8 หุน = 1 นิ้ว
- ท่อ PVC ต้องบอกชั้นความหนาด้วย → งานนี้ใช้ **ชั้น 8.5 หรือ 13.5 (ท่อสีฟ้า)** ได้ทั้งคู่

### หางปลาไหล (Hose barb)
- ปลายต่อที่เป็นหยัก ๆ ให้สวมสายยางแล้วรัดด้วยเข็มขัด · ต้องรู้ขนาด = เส้นผ่านศูนย์กลางนอกของหางปลาไหล (มม.) แล้วซื้อสายยางที่ "รูใน" เท่านั้น

### เข็มขัดรัดสายยาง (Hose clamp)
- **คำค้น:** `เข็มขัดรัดสายยาง สแตนเลส` (แบบใช้ไขควงขัน)

### ข้อต่อทะลุถัง (Bulkhead fitting)
- ข้อต่อที่เจาะผนังถังแล้วสอดทะลุ ขันน็อตประกบแหวนยางทั้งด้านในและนอก ไม่รั่ว — ใช้ 2 ที่:
  - **ท่อล้นถัง 3** ขนาด **6 หุน** · **คำค้น:** `ข้อต่อถังน้ำ 6 หุน` · `ข้อต่อทะลุถัง PVC 3/4` · `bulkhead fitting 3/4`
  - **ทางออกน้ำใกล้ก้นถัง 1 และ 2** ขนาด **4 หุน** (อยู่ใต้ระดับน้ำ ต้องขันแน่นและทดสอบรั่ว) · **คำค้น:** `ข้อต่อถังน้ำ 4 หุน` · เลือกแบบที่ **ปลายด้านนอกเป็นเกลียวนอก** จะขันบอลวาล์วเข้าได้ตรง ๆ
- เจาะรูด้วย **ดอกโฮลซอว์ (hole saw)** หรือ **ดอกสว่านขั้นบันได (step drill)** ขนาดตามที่ร้านบอก

### ท่อล้น (Overflow)
- รูระบายน้ำส่วนเกินใกล้ขอบถัง ต่อสายลงท่อระบายน้ำ → ถ้าปั๊มเติมไม่ยอมหยุด น้ำจะไหลทิ้ง ไม่ล้นถัง · **ห้ามต่อลงระบบปูเด็ดขาด**

### กาลักน้ำ (Siphon) + รูเบรกกาลักน้ำ (Siphon break)
- **กาลักน้ำ:** ถ้าสายยางเต็มไปด้วยน้ำ และปลายสายอยู่ **ต่ำกว่าผิวน้ำต้นทาง** น้ำจะไหลต่อเองเรื่อย ๆ **แม้ปั๊มดับแล้ว** → ถังพักอาจถูกดูดจนเกือบหมด
- **รูเบรกกาลักน้ำ:** เจาะรูเล็ก ~3 มม. ที่ท่อแข็งช่วงที่อยู่ **ในถังต้นทาง เหนือระดับน้ำสูงสุด** — ตอนปั๊มเดินจะมีน้ำพุ่งออกรูนิดหน่อย (ตกกลับลงถังเดิม ไม่เป็นไร) ตอนปั๊มดับ อากาศจะวิ่งเข้ารู ตัดสายน้ำทันที
- เป็นเทคนิคมาตรฐานของคนเลี้ยงตู้ปลาทะเล · **คำค้น:** `siphon break hole sump`

### ช่องว่างอากาศ (Air gap)
- ปลายสายที่ปล่อยน้ำลงถัง ให้ **ลอยเหนือผิวน้ำอย่างน้อย 3 ซม.** ไม่จุ่มลงไป → น้ำไหลย้อนกลับไม่ได้

### ปั๊มลม / หัวทราย / วาล์วกันย้อน
- **ปั๊มลม (ตู้ปลา)** เป่าอากาศผ่าน **สายออกซิเจน** ไปที่ **หัวทราย** ในน้ำ → ฟองอากาศคนน้ำ + ไล่คลอรีนเร็วขึ้น · แนะนำ `ปั๊มลม 4 ทาง` (ใช้ได้ทั้งถัง 1, 2, 3)
- **วาล์วกันน้ำย้อน (Air check valve):** ใส่กลางสายลม กันน้ำไหลย้อนเข้าปั๊มลมตอนไฟดับ · **คำค้น:** `เช็ควาล์ว สายออกซิเจน ตู้ปลา`

### ATO (Auto Top Off)
- ระบบ "เติมน้ำจืดชดเชยน้ำระเหย" ของคนเลี้ยงตู้ปลาทะเล = **หลักการเดียวกับโปรเจกต์นี้** (ถังน้ำจืด → ปั๊ม → ซัมพ์ + เซนเซอร์ระดับ + กันล้น)
- ค้นไอเดีย/อะไหล่ด้วยคำว่า `ATO ตู้ปลาทะเล` · `auto top off DIY` · มีชุดสำเร็จรูปขาย (อาจใช้แทนเฟส 5 ได้)

## ง. น้ำและเคมี

### คลอรีน vs คลอรามีน
- **คลอรีนอิสระ (free chlorine):** ระเหยออกได้ถ้าพักน้ำ 24 ชม. หรือเป่าลมด้วยหัวทรายไม่กี่ชั่วโมง
- **คลอรามีน (chloramine):** คลอรีนที่จับกับแอมโมเนีย **พักน้ำ/เป่าลมก็ไม่หาย** ต้องใช้น้ำยาปรับสภาพน้ำ
- **วิธีเช็ค:** ซื้อ `แผ่นทดสอบคลอรีน free total` (Free & Total Chlorine test strips) → จุ่มน้ำประปาที่พักแล้ว 24 ชม. ถ้าทั้ง Free และ Total ≈ 0 = ใช้ได้ · ถ้า Free ≈ 0 แต่ Total ยังสูง = เป็นคลอรามีน

### Fail-safe
- ออกแบบให้ "เมื่ออะไรพัง ผลที่ได้คือหยุด ไม่ใช่ทำงานค้าง" เช่น สายลูกลอยขาด → ระบบเข้าใจว่าถังเต็ม → ไม่ปั๊ม
