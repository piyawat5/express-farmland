# 🔧 เฟส 1 — ติดตั้งหน้างาน

> **ทำหลังผ่านเฟส 0 ครบแล้วเท่านั้น** · ผังสาย/ท่อทั้งหมดอยู่ใน [03-wiring.md](./03-wiring.md)
> **ผลลัพธ์:** ใส่โซดา 2 ช้อนลงถัง 3 → กดปุ่มเดียว → วาล์วปล่อยน้ำจากถังที่พักครบลงถัง 3 → ผสม → ปั๊มปล่อยเข้าระบบปูช้า ๆ เอง
> **แนวทาง (ผู้ใช้ยืนยัน 2026-09-19):** ถัง 1/2 → ถัง 3 **ไหลเองผ่านโซลินอยด์ V1, V2** · ถัง 3 → ถังกรอง **ปั๊ม P3** (หรือวาล์ว V3 ถ้าความสูงพอ)
> ⚠️ **เฟิร์มแวร์เฟส 1 ยังไม่ได้เขียน** — Claude จะเขียนตามข้อ 10 เมื่อของมาครบ (ระหว่างนั้นทำข้อ 0–7 ได้เลย)

## 0. ก่อนเริ่ม (ทำได้ตั้งแต่วันนี้ ไม่ต้องรอของ)

### 0.1 เช็คว่าน้ำประปาบ้านใช้คลอรีนหรือคลอรามีน
1. ดูบิลค่าน้ำ: โลโก้ **การประปานครหลวง (กปน.)** = น้ำจากการประปา · ถ้าเป็นบิลของนิติบุคคลหมู่บ้าน/ประปาหมู่บ้าน ให้ถามนิติฯ ว่าซื้อน้ำจากไหน
2. ใช้แผ่นทดสอบคลอรีน (Free & Total):
   - จุ่ม **น้ำประปาจากก๊อกสด ๆ** → จดค่า Free และ Total
   - จุ่ม **น้ำในถังพักที่พักครบ 24 ชม.** → จดค่าอีกครั้ง
3. อ่านผล:
   - ถังพัก 24 ชม. ได้ Free ≈ 0 และ Total ≈ 0 → **ใช้วิธีพักน้ำได้** ✓ (น่าจะเป็นกรณีนี้)
   - ถังพัก Free ≈ 0 แต่ Total ยังสูง → **คลอรามีน** → พักน้ำไม่ช่วย ต้องใช้น้ำยาปรับสภาพน้ำ → **หยุดก่อน แจ้ง Claude** (ต้องปรับแผน)
4. (แถม) ลองเป่าหัวทรายในถังพักแล้วทดสอบทุก 4 ชม. → รู้ว่าคลอรีนหายเร็วแค่ไหน (อาจลดเวลาล็อกจาก 24 ชม. ได้ในอนาคต แต่เฟส 1 ใช้ 24 ชม. ไว้ก่อน)

### 0.2 ปริมาตรน้ำทั้งระบบปู
- แผนนี้สมมติ **500 ลิตร** (ตามข้อมูลใน seed) → ถัง 3 เต็มถึงท่อล้น ~20 ลิตร = ~4% ของระบบ ความเค็มตกนิดเดียว
- **ถ้าระบบจริงเล็กกว่า 300 ลิตร แจ้ง Claude** — ต้องใช้ถัง 3 ที่เล็กลง หรือย้ายท่อล้นให้ต่ำลง

### 0.3 ตวง "5 ขัน"
- ใช้ขันเดิมตวงน้ำ 5 ขันใส่ถังตวง/ขวด → จดว่ากี่ลิตร (ใช้ตั้งตำแหน่งลูกลอยบนในข้อ 4)

### 0.4 วัดความสูง 3 ค่า (ใช้ตัดสินขนาดฐานและปั๊ม/วาล์ว — ส่งให้ Claude ดูได้)
| # | วัดอะไร | ใช้ทำอะไร |
|---|---|---|
| A | **ความสูงของถัง 3** ที่จะซื้อ (ขอบบน จากพื้น) | ตามกฎข้อ 1: รูทางออกถัง 1/2 ต้องสูงกว่า A + 5 ซม. → รู้ว่าต้องยกถัง 1/2 กี่ ซม. |
| B | **ผิวน้ำในถังกรอง** สูงจากพื้นกี่ ซม. (ตอนระบบทำงานปกติ) | ถ้าวางถัง 3 ให้ก้นถังสูงกว่า B ได้ → ใช้วาล์ว V3 แทนปั๊มได้ (แต่ถัง 1/2 ต้องยกสูงขึ้นตาม) |
| C | **ยกถัง 1/2 ได้สูงสุดกี่ ซม.** แบบมั่นคง | เทียบกับ A (และ B) ว่าเป็นไปได้ไหม |

- ส่วนใหญ่จะออกมาเป็น: **ถัง 3 วางพื้น + ยกถัง 1/2 ราว 25–35 ซม. + ปั๊ม P3** (ดูรูป [03 ข้อ 6.0](./03-wiring.md))
- จำไว้: ถังเปล่าเบา แต่ **ตอนเต็ม น้ำ 1 ลิตร = 1 กก.** → ฐานต้องเรียบ แน่น ไม่โยก

## 1. ทดสอบโซลินอยด์ที่หัวน้ำต่ำ — **ก่อนเจาะถังจริง**

> วาล์ว 2W-160-15 เขียนว่าเปิดได้ที่แรงดัน 0 แต่ของบางล็อตเปิดไม่สุด/ปิดไม่สนิทเมื่อหัวน้ำต่ำมาก → ทดสอบกับของจริงก่อน ถ้าไม่ผ่าน จะได้เปลี่ยนไปใช้ปั๊มแทนก่อนเจาะถังพัก

1. ต่อชุดไฟตาม [03 ข้อ 4.1](./03-wiring.md#41-ไฟเลี้ยง) บนโต๊ะ **วัด 5V ที่ Mini560 ก่อนต่อ ESP32**
2. ต่อวาล์ว 1 ตัวตาม [03 ข้อ 3.1 และ 4.2](./03-wiring.md#31-ต่อคอยล์วาล์ว--ไดโอด-ทำในปลั๊ก-din-ที่หัววาล์ว) แถว M1, M4, M5, D1 (อย่าลืมไดโอด)
3. จำลองหัวน้ำ: ถังน้ำ/ถังหูหิ้วเต็ม ๆ วางบนเก้าอี้หรือบล็อก **สูงเท่ากับที่จะยกถังพักจริง** → สายยางจากก้นถัง (ใช้สายยางดูดกาลักน้ำให้เต็มก่อน หรือใช้ถังที่มีก๊อก) → วาล์ว → สายยางลงถังเปล่าบนพื้น
4. อัปโหลดโค้ดบทที่ 5 ของเฟส 0 → กด "เปิด"/"ปิด" บนมือถือ
5. **ผ่านเมื่อ:**
   - เปิด → น้ำไหลออกต่อเนื่อง ไม่ใช่แค่ซึม · จับเวลาเติมน้ำ 5 ขัน (ควรไม่เกิน ~5 นาที)
   - ปิด → น้ำหยุดภายใน 2 วิ และ **ไม่มีหยดซึมใน 10 นาที**
   - เปิด-ปิดซ้ำ 10 รอบแล้ว ESP32 **ไม่รีสตาร์ตเอง** (ถ้ารีสตาร์ต = ไดโอดหลุด/กลับด้าน)
   - ถอดปลั๊กอะแดปเตอร์ตอนวาล์วเปิด → น้ำต้องหยุดทันที (NC ✓)
6. **ถ้าไม่ผ่าน:** ลองยกถังทดสอบสูงขึ้น 10–20 ซม. แล้วทดสอบซ้ำ · ยังไม่ผ่าน → แจ้ง Claude เปลี่ยนขานั้นเป็นปั๊ม DC40 แบบเดียวกับ P3

## 2. ติดตั้งถัง 1 และ 2

1. **ทำฐาน** ตามความสูงที่วัดในข้อ 0.4 — บล็อกคอนกรีตวางเต็มแผ่นบนพื้นเรียบ หรือขาตั้งถังน้ำ · เช็คระดับด้วยแอประดับน้ำในมือถือ
2. **เจาะรูทางออก** ข้างถัง สูงจากก้นถังด้านใน 3–5 ซม. หันไปทางถัง 3 · ขนาดรูตามที่ร้านบอกสำหรับข้อต่อถังน้ำ 4 หุน · ลบคมรูให้เรียบ
3. ใส่ข้อต่อถังน้ำ (แหวนยางด้านในและนอก) ขันแน่นพอดี **อย่าขันจนถังบิด**
4. ต่อชุดวาล์วตาม [03 ข้อ 6.2](./03-wiring.md#62-ชุดวาล์วที่ถัง-1-และถัง-2): บอลวาล์ว → นิปเปิ้ล → วายสเตรนเนอร์ → นิปเปิ้ล → โซลินอยด์ → หางปลาไหล
   - พันเทปพันเกลียวทุกเกลียวนอก · ลูกศรชี้ออกจากถัง · ใช้ประแจ 2 อัน ไม่ให้ข้อต่อถังหมุนตาม
   - หาอะไรรองใต้โซลินอยด์ อย่าให้ห้อยกับผนังถัง
5. **ทดสอบรั่ว:** ปิดบอลวาล์ว → เติมน้ำเต็มถัง ทิ้งไว้ 1 คืน → รอบข้อต่อถังและทุกเกลียวต้องแห้ง
6. ต่อสายยาง 4 หุนจากหางปลาไหลไปถัง 3 — **ลาดลงตลอดทาง** ไม่มีช่วงย้อนขึ้น (ช่วงย้อนขึ้นจะมีฟองอากาศค้าง น้ำไหลช้า) · ยึดกับพื้น/ผนังไม่ให้โดนเหยียบพับ

## 3. (ไม่บังคับ) ลูกลอยถังใกล้หมดในถัง 1, 2

- วาล์วแรงโน้มถ่วงไม่มีปัญหาเดินแห้ง ถังหมด = น้ำหยุดไหล → เฟิร์มแวร์ฟ้อง "เติมไม่เต็มในเวลา" อยู่แล้ว
- ถ้าอยากให้หน้าเว็บบอกชัด ๆ ว่า "ถัง 1 ใกล้หมด" ก่อนเริ่มรอบ → ทำเสาเซนเซอร์ถังละ 1 ต้น (วิธีเดียวกับข้อ 4) ตั้งลูกลอยสูงกว่ารูทางออก ~5 ซม.

## 4. เตรียมถัง 3 + เสาเซนเซอร์

**ถัง 3:**
1. วางปั๊ม P3 ที่ก้นถัง 3 → ขีดเส้น **L** ที่ระดับ "ยอดปั๊ม + 3 ซม."
2. เติมน้ำถึงเส้น L → เทน้ำเพิ่มอีก **5 ขัน** → ขีดเส้น **H** ที่ผิวน้ำ (ปริมาณระหว่าง L กับ H = น้ำที่เติมเข้าระบบต่อ 1 รอบ)
3. ขีดตำแหน่ง **ท่อล้น** สูงกว่า H อย่างน้อย 3 ซม. และต่ำกว่าขอบถังอย่างน้อย 2 ซม. → เทน้ำออก
4. เจาะรูท่อล้น → ใส่ข้อต่อถังน้ำ 6 หุน → ต่อสายยาง 6 หุนลงท่อระบายน้ำ **ลาดลงตลอด**
5. **ทดสอบรั่ว:** เติมน้ำจนล้นออกท่อล้น ทิ้งไว้ 1 ชม. → รอบข้อต่อต้องแห้ง
6. เจาะรูเล็กใกล้ขอบถัง (เหนือท่อล้น) ไว้ร้อยเคเบิลไทร์ยึด: เสาเซนเซอร์ 2 ต้น + ปลายสายจาก V1, V2 + สายยางขาออกของ P3

**เสาเซนเซอร์ (ดูรูป [03 ข้อ 6.5](./03-wiring.md#65-เสาเซนเซอร์-ใส่ลูกลอยโดยไม่ต้องเจาะถังใต้น้ำ)) ทำ 2 ต้น:**
1. ตั้งทิศลูกลอยด้วยมัลติมิเตอร์ตาม [03 ข้อ 5](./03-wiring.md#5-ติดลูกลอยแบบ-fail-safe-สำคัญ) → **T3_HIGH ตั้งแบบตัวบน, T3_LOW ตั้งแบบตัวล่าง** → ติดป้ายที่สาย
2. เจาะรู 10 มม. กลางฝาครอบ PVC 6 หุน
3. ร้อยสายลูกลอยผ่านรูฝาครอบ → ผ่านน็อต → ขึ้นไปในท่อ PVC → ขันเกลียวลูกลอยกับน็อตด้านในฝาครอบให้แน่น (แกนลูกลอยชี้ลง)
4. สวมฝาครอบเข้าปลายท่อ (ไม่ต้องทากาว จะได้ถอดซ่อมได้)
5. ปลายล่างของเสา (ตำแหน่งลูกลอย) ให้อยู่ที่เส้น H หรือ L — **ตัดยาวไว้ก่อน ค่อยปรับด้วยการเลื่อนขึ้นลง**
6. ต่อสายลูกลอยให้ยาวถึงกล่องด้วย Wago 221-412 **ที่ปลายบนของเสา (จุดแห้ง)** หุ้มกันละออง

**ปลายสายจาก V1, V2:** ยึดกับขอบถัง 3 ให้ปลายสาย **แขวนเหนือระดับท่อล้น** (ห้ามจุ่มน้ำ)

## 5. ปั๊ม P3 และสายไปถังกรอง

1. ปั๊ม P3 วางก้นถัง 3 · ต่อสายยาง + รัดเข็มขัด
2. สายยางขึ้นแนบผนังถัง 3 ยึดกับขอบถังด้วยเคเบิลไทร์ → **เจาะรู 3 มม. ที่สายยางช่วงที่อยู่ในถัง 3 ใต้ขอบนิดเดียว (เหนือระดับท่อล้น)** (ดู [03 ข้อ 6.4](./03-wiring.md#64-เส้นปั๊ม-p3-รูเบรกกาลักน้ำ--ช่องว่างอากาศ))
3. ปลายสายอีกข้างแขวนเหนือผิวน้ำถังกรอง **≥ 3 ซม. ห้ามจุ่มน้ำเด็ดขาด** (ไม่งั้นน้ำจากระบบปูไหลย้อนกลับมาถัง 3 แล้วออกท่อล้นทิ้ง)
4. ถ้าข้อ 0.4 ได้ผลว่าใช้วาล์ว V3 แทน: ทำชุดวาล์วแบบข้อ 2 ที่ถัง 3 แทนปั๊ม

## 6. ปั๊มลม

1. ปั๊มลม **เสียบปลั๊กผนังตรง เปิดตลอด 24 ชม.** (ไม่ผ่านกล่องควบคุม)
2. วางปั๊มลม **สูงกว่าผิวน้ำ** ทุกถัง + ใส่ **เช็ควาล์ว** กลางสายลมทุกเส้น (หัวลูกศรบนเช็ควาล์วชี้ไปทางหัวทราย)
3. หัวทรายลงถัง 3 (จำเป็น) + ถัง 1, 2 (ช่วยไล่คลอรีน — แนะนำ) · หัวทรายในถัง 1, 2 วางห่างรูทางออก

---

## 7. ติดตั้งกล่องควบคุม

1. เจาะฝากล่อง 3 รูใส่ปุ่ม 22 มม. (เขียว B1 / น้ำเงิน B2 / แดง B3) · เจาะใต้กล่องใส่เคเบิ้ลแกลนด์
2. จัดวางตาม [03 ข้อ 7](./03-wiring.md#7-จัดของในกล่องควบคุม) ติดเทปกาว 2 หน้า + เคเบิลไทร์
3. ต่อสายตาม [03 ข้อ 4](./03-wiring.md#4-เฟส-1--ตารางต่อสายทุกเส้น-ต่อทีละแถว-แล้วติ๊ก) **ทีละแถว ติ๊กทีละแถว** — ห้ามเสียบปลั๊กจนต่อครบและตรวจแล้ว
4. ติดกล่องใต้หลังคา สูงกว่าถังทุกใบ สายเข้าจากด้านล่าง ทำ drip loop

## 8. ทดสอบก่อนใช้จริง (ต้องผ่านทุกข้อ)

> ใช้เฟิร์มแวร์เฟส 1 ที่ Claude เขียนให้ (มีหน้า "ทดสอบ" สั่งวาล์ว/ปั๊มทีละตัว 5 วินาทีได้)

| ✔ | # | ทดสอบ | ผ่านเมื่อ |
|---|---|---|---|
| ☐ | T1 | เสียบปลั๊ก | ESP32 ติด, รีเลย์ **ไม่แกร๊กเลย**, หน้าเว็บเปิดได้ |
| ☐ | T2 | ยกลูกลอยถัง 3 ทั้ง 2 ตัวขึ้นลงด้วยมือ | หน้าเว็บเปลี่ยนตามถูก |
| ☐ | T3 | ถอดสายลูกลอยทีละตัว | T3_HIGH ขึ้น "เต็ม" · T3_LOW ขึ้น "หมด" |
| ☐ | T4 | สั่ง V1, V2, P3 ทีละตัว 5 วิจากหน้าทดสอบ | น้ำไหลถูกทิศ ถูกถัง · ESP32 ไม่รีสตาร์ต |
| ☐ | T5 | ปิด V1 / V2 | น้ำหยุดภายใน 2 วิ · ไม่มีหยดจากปลายสายใน 10 นาที |
| ☐ | T6 | กาลักน้ำเส้น P3: เปิด P3 จนน้ำไหลลงถังกรอง แล้วหยุด | น้ำหยุดไหลภายใน ~5 วิ · ถ้ายังไหล = รูเบรกตัน/เล็กไป หรือปลายสายจุ่มน้ำ |
| ☐ | T7 | ท่อล้น: เปิด V1 ค้างไว้เอง (หน้าทดสอบ) จนน้ำเกินท่อล้น | น้ำออกท่อล้นลงท่อระบายทัน ไม่ล้นขอบ ไม่รั่ว |
| ☐ | T8 | **รอบเต็มแบบไม่เข้าระบบปู:** ย้ายปลายสาย P3 ไปใส่ถังเปล่า แล้วกดปุ่มถัง 1 | เติมหยุดที่เส้น H → รอผสม → ปล่อยเป็นจังหวะ → หยุดที่เส้น L → ปี๊บ 2 ครั้ง · น้ำในถังเปล่า ≈ 5 ขัน |
| ☐ | T9 | ระหว่างเติม ถอดสาย T3_HIGH | V1 ปิดทันที + แจ้งเตือน |
| ☐ | T10 | ระหว่างปล่อย กดปุ่มแดง | P3 หยุดทันที |
| ☐ | T11 | ระหว่างเติม ถอดปลั๊กอะแดปเตอร์ แล้วเสียบคืน | น้ำหยุดทันทีตอนไฟดับ · เสียบคืนแล้ว **ไม่ทำต่อเอง** + หน้าเว็บแจ้ง "รอบก่อนหน้าถูกขัดจังหวะ" |
| ☐ | T12 | กดค้างปุ่มเขียว 3 วิ แล้วกดสั้นปุ่มเขียว | ปี๊บยาว (ล็อกแล้ว) → ปี๊บสั้น 3 ครั้ง (ปฏิเสธ) · เว็บโชว์ล็อกเหลือ ~24 ชม. |
| ☐ | T13 | ปิดบอลวาล์วถัง 1 แล้วกดเริ่มรอบถัง 1 | ครบเวลา `FILL_TIMEOUT_MIN` → หยุด + แจ้ง "ถัง 1 อาจหมด หรือวาล์วไม่เปิด" |
| ☐ | T14 | **ใช้จริงครั้งแรก:** ต่อปลายสาย P3 กลับที่ถังกรอง วัดความเค็ม+อัลคาไลน์ก่อนเริ่ม และ 2 ชม. หลังจบ | ค่าเปลี่ยนใกล้เคียงตอนเติมมือ · บันทึกในแอปฟาร์ม |

## 9. วิธีใช้งานประจำ

**เมื่อเติมน้ำประปาลงถัง 1 หรือ 2 (ทุกครั้ง):**
→ กดปุ่มของถังนั้น **ค้าง 3 วินาที** จนได้ยินปี๊บยาว = ระบบล็อกถังนั้น 24 ชม. (ลืมกด = ระบบไม่รู้ว่ายังมีคลอรีน!)

**เมื่อจะเติมน้ำเข้าระบบปู:**
1. หย่อนเบกกิ้งโซดา **2 ช้อน** ลงถัง 3
2. กดปุ่มของถังที่พักครบ (กดสั้น) — จำไม่ได้ว่าถังไหน? กดถังไหนก็ได้ ถ้ายังล็อกอยู่มันจะปี๊บ 3 ครั้งไม่ยอมทำงาน
3. ไปทำอย่างอื่นได้เลย — ได้ยินปี๊บ 2 ครั้ง = เสร็จ (ประมาณ 1–2 ชม.)

**เสียงปี๊บ:**
| เสียง | ความหมาย |
|---|---|
| ปี๊บยาว 1 ครั้ง | รับคำสั่ง / บันทึกล็อกถังแล้ว |
| ปี๊บสั้น 3 ครั้ง | ไม่ทำตาม (ถังยังล็อก / ถัง 3 เต็มอยู่แล้ว / เพิ่งเติมไปไม่นาน) → เปิดหน้าเว็บดูเหตุผล |
| ปี๊บ 2 ครั้ง | จบรอบ สำเร็จ |
| ปี๊บซ้ำทุก 5 นาที | **มีปัญหา ระบบหยุดรอคน** → เปิดหน้าเว็บ แก้แล้วกดปุ่มแดงค้าง 3 วิ เพื่อล้าง |

**ดูแลรายเดือน:** ปิดบอลวาล์ว → ถอดตะแกรงวายสเตรนเนอร์มาล้าง → ใส่คืน → เปิดบอลวาล์ว

**จดไว้ 2 สัปดาห์แรก (ใช้ตั้งค่าเฟส 2):** เวลาเติมถัง 3 ต่อรอบ, เวลาปล่อยต่อรอบ, เติมกี่รอบต่อสัปดาห์, ความเค็มก่อน-หลัง

## 10. สเปกเฟิร์มแวร์เฟส 1 (สำหรับ Claude)

> ภาษา: Arduino C++ (Arduino IDE 2, board "ESP32 Dev Module") · ขาตาม [03 ข้อ 1](./03-wiring.md#1-ผังขา-esp32-pin-map--เฟส-0--เฟส-1) · ทำงานได้ 100% โดยไม่มีอินเทอร์เน็ต
> เรียกตัวที่ปล่อยน้ำเข้าถัง 3 ว่า "ตัวเติม" (V1, V2) และตัวที่ปล่อยออกจากถัง 3 ว่า "ตัวปล่อย" (P3 หรือ V3 — ตั้งค่าได้ว่าเป็นปั๊มหรือวาล์ว ลอจิกเหมือนกัน)

### 10.1 สถานะ (state machine)

| สถานะ | ทำอะไร | ออกจากสถานะเมื่อ |
|---|---|---|
| `IDLE` | ปิดทุกตัว รอคำสั่ง | ได้คำสั่งเริ่มรอบ (ผ่านเงื่อนไข 10.3) |
| `FILLING(1\|2)` | เปิดวาล์ว V1 หรือ V2 ค้าง | T3_HIGH = เต็ม → `MIXING` · หมดเวลา `FILL_TIMEOUT_MIN` → `ERROR` ("ถัง X อาจหมด หรือวาล์วไม่เปิด") · T{X}_LOW = หมด (ถ้าเปิดใช้) → `ERROR` · ปุ่มแดง → `IDLE` |
| `MIXING` | ปิดทุกตัว รอ `MIX_MIN` นาที (หัวทรายเปิดอยู่แล้ว) | ครบเวลา → `RELEASING` · ปุ่มแดง → `IDLE` |
| `RELEASING` | ตัวปล่อยเปิด `PULSE_ON_SEC` / ปิด `PULSE_OFF_SEC` วนไป | T3_LOW = หมด → `DONE` · หมดเวลา `RELEASE_TIMEOUT_MIN` → `ERROR` · ปุ่มแดง → `IDLE` |
| `DONE` | ปี๊บ 2 ครั้ง, เริ่มนับ `MIN_GAP_HOURS`, บันทึกสถิติ | ทันที → `IDLE` |
| `ERROR(code)` | ปิดทุกตัว ปี๊บซ้ำทุก 5 นาที โชว์เหตุผลบนเว็บ | ปุ่มแดงค้าง 3 วิ หรือกดล้างบนเว็บ → `IDLE` |
| `INTERRUPTED` | (หลังบูต ถ้า NVS บอกว่ามีรอบค้าง) ปิดทุกตัว โชว์ว่าค้างที่ขั้นไหน | ผู้ใช้กดรับทราบ → `IDLE` · **ห้ามทำต่อเอง** |

### 10.2 ปุ่ม
- **B1/B2 กดสั้น** = เริ่มรอบจากถัง 1/2 · **กดค้าง 3 วิ** = "เพิ่งเติมประปาถังนี้" → ล็อก `LOCK_HOURS` (กดซ้ำตอนล็อกอยู่ = เริ่มนับใหม่)
- **B3 กดสั้น** = หยุดทุกอย่าง → `IDLE` · **กดค้าง 3 วิ** = ล้าง `ERROR` / รับทราบ `INTERRUPTED`

### 10.3 เงื่อนไขเริ่มรอบจากถัง X (ไม่ผ่านข้อใด = ปี๊บสั้น 3 + โชว์เหตุผล)
1. สถานะ `IDLE`
2. ถัง X ไม่ถูกล็อก
3. T{X}_LOW = มีน้ำ — **เฉพาะเมื่อตั้งค่า `USE_SOURCE_FLOATS` = เปิด** (ลูกลอยถัง 1/2 ไม่บังคับ)
4. T3_HIGH ≠ เต็ม (ถ้าเต็มอยู่แล้ว ให้ใช้ปุ่ม "ปล่อยน้ำถัง 3 ตอนนี้" บนเว็บแทน)
5. พ้น `MIN_GAP_HOURS` นับจากรอบก่อน (กันเติมซ้ำ — ข้ามได้จากเว็บพร้อมยืนยัน)

### 10.4 กฎความปลอดภัย (ห้ามละเมิด)
- บรรทัดแรกของ `setup()` = สั่งขารีเลย์ทุกขาเป็น LOW
- **เปิดได้ทีละตัว** (V1 / V2 / ตัวปล่อย ห้ามพร้อมกัน)
- **"หยุดเร็ว เริ่มช้า":** เงื่อนไขหยุด (เต็ม/หมด/ปุ่มแดง) ทำทันทีที่อ่านได้ · เงื่อนไขเริ่มต้องอ่านค่าเดิมต่อเนื่อง 2 วิ (กันคลื่นน้ำจากหัวทรายทำลูกลอยกระพริบ)
- เปิด watchdog — โปรแกรมค้าง → รีบูต → รีเลย์ดับ → วาล์ว NC ปิดเอง
- **เวลาล็อก/เวลาเว้นช่วงนับแบบ "เหลืออีกกี่นาที"** ลด 1 ทุกนาที เซฟลง NVS ทุก 10 นาที → **ไม่ต้องพึ่งอินเทอร์เน็ต** และถ้าไฟดับ เวลาที่ไฟดับไม่ถูกนับ = ล็อกนานขึ้น (ทิศทางที่ปลอดภัย)
- บันทึกสถานะรอบลง NVS ทุกครั้งที่เปลี่ยนสถานะ (ใช้ตรวจ `INTERRUPTED` ตอนบูต)
- หน้าทดสอบสั่งได้ครั้งละ ≤ 5 วิ ยกเว้นทดสอบท่อล้น (T7) ที่ต้องกดค้างเอง

### 10.5 ค่าตั้งเริ่มต้น (แก้ได้จากหน้าเว็บ เก็บใน NVS)

| ค่า | เริ่มต้น | หมายเหตุ |
|---|---|---|
| `LOCK_HOURS` | 24 | ปรับลดได้หลังทดสอบคลอรีน (0.1 ข้อ 4) |
| `FILL_TIMEOUT_MIN` | 10 | หลังใช้จริง ตั้ง = เวลาเติมจริง × 2 (จากข้อ 1 ได้ค่าคร่าว ๆ แล้ว) |
| `MIX_MIN` | 30 | |
| `PULSE_ON_SEC` / `PULSE_OFF_SEC` | 5 / 180 | ปรับให้ 1 รอบปล่อยใช้เวลา ~1–2 ชม. |
| `RELEASE_TIMEOUT_MIN` | 240 | |
| `MIN_GAP_HOURS` | 8 | |
| `USE_SOURCE_FLOATS` | ปิด | เปิดเมื่อติดลูกลอยถัง 1/2 (ข้อ 3) |
| `RELEASE_IS_VALVE` | ปิด (= ปั๊ม P3) | เปิดถ้าใช้วาล์ว V3 |

### 10.6 หน้าเว็บ (มือถือ, WiFi บ้าน, ชื่อ `farm-water.local`)
- **สถานะ:** ขั้นปัจจุบัน + เวลาที่เหลือ, ลูกลอย, ถัง 1/2 ล็อกเหลือกี่ชม., ผลรอบล่าสุด, ข้อความ error
- **ปุ่ม:** เริ่มจากถัง 1 / ถัง 2 · ปล่อยน้ำถัง 3 ตอนนี้ · หยุด · บันทึกเติมประปาถัง 1 / 2 · ปลดล็อก (ต้องยืนยัน) · ล้าง error
- **หน้าทดสอบ:** เปิด V1 / V2 / ตัวปล่อย ทีละตัว 5 วิ (ใช้ในข้อ 8)
- **ตั้งค่า:** ฟอร์มแก้ค่าในข้อ 10.5
- **ประวัติ:** 20 เหตุการณ์ล่าสุด (ใช้เวลา NTP ถ้ามีเน็ต ไม่มีก็แสดงเป็น "x นาทีที่แล้ว")
- (แนะนำ) อัปเดตเฟิร์มแวร์ผ่าน WiFi (OTA) จะได้ไม่ต้องถอดกล่องมาเสียบ USB
