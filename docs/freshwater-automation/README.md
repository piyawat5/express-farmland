## 1. ปัญหาเดิม (pain point จากผู้ใช้)

วิธีเติมน้ำจืดเข้าระบบปูตอนนี้:
1. มีถังพักน้ำประปา 2 ถัง (ถัง 1, ถัง 2) ขนาดประมาณถังขยะข้างทาง ใช้สลับกัน — ต้องพักไว้ให้คลอรีนหมดก่อนใช้
2. ใช้ขันตักน้ำจากถังพักใส่กะละมัง → ใส่เบกกิ้งโซดา 2 ช้อน → เอาไม้คนให้ละลาย → แบกกะละมังไปเทลงระบบทีละนิด
3. เติมครั้งละประมาณ **5 ขัน** (ตักใส่ถังหูหิ้ว 16 ลิตร) — ช่วงน้ำระเหยไวต้องเติมวันเว้นวัน

อาการที่เจอ:
- **ปวดหลัง** จากการแบกกะละมังหนัก + อากาศร้อน
- ต้องเดินไป-กลับตักน้ำจากถังพัก (ห่างจากระบบปู 3–4 เมตร)
- **ลืมว่าถังพักถังไหนเพิ่งเติมน้ำประปา** → บางครั้งตักผิดไปเอาถังที่ยังมีคลอรีน

## 2. สิ่งที่ผู้ใช้อยากได้

1. ต่อถัง 1 และ 2 เข้าถังใหม่ (**ถัง 3**) — ระบบเลือกเองว่าถังไหนพักครบเกิน 1 วันแล้วค่อยดูดเข้าถัง 3 จนถึงระดับที่กำหนด
2. ใส่เบกกิ้งโซดา 2 ช้อนลงถัง 3 ก่อนถึงเวลาเติม (วิธีไหนก็ได้)
3. ในถัง 3 มีหัวทรายออกซิเจนตีให้โซดาละลาย (แทนการคนด้วยไม้)
4. ถึงเวลานัด ปล่อยน้ำจากถัง 3 เข้าระบบปู **แบบค่อย ๆ ปล่อย**

## 3. ข้อมูลหน้างาน (ผู้ใช้ตอบ 2026-09-19)

## 4. การตัดสินใจหลัก (และเหตุผล)

| # | ตัดสินใจ | เหตุผล |
|---|---|---|
| D1 | **สมอง = ESP32 DevKit V1, เขียนด้วย Arduino IDE 2 (ภาษา C++)** | ถูก (~200฿), มี WiFi ในตัว, ตัวอย่างภาษาไทยเยอะ, ต่อเข้าเว็บ express-farmland ได้ตรง ๆ ในอนาคต (ESPHome ง่ายกว่าแต่ต้องมี Home Assistant แยกอีกระบบ) |
| D2 | **ถัง 1–2 → ถัง 3: แรงโน้มถ่วง + โซลินอยด์วาล์ว 12V แบบ NC ที่เปิดได้ที่แรงดัน 0 bar** (วาล์ว V1, V2) | ผู้ใช้เลือก (ถังยกได้นิดหน่อย) · เงียบ ไม่มีปั๊มให้เสีย ไม่มีปัญหาปั๊มเดินแห้ง · ไฟดับ = วาล์วปิดเอง · **กฎความสูง: รูทางออกถัง 1–2 ต้องสูงกว่าขอบบนถัง 3 อย่างน้อย 5 ซม.** → ถัง 3 จึงต้องเป็นทรงเตี้ย |
| D2b | **ถัง 3 → ถังกรอง: ปั๊ม DC 12V จุ่มน้ำ (P3) เป็นค่าเริ่มต้น** | ถัง 3 วางบนพื้น (เพื่อให้ถัง 1–2 ยกนิดเดียว) จึงมักต่ำกว่าผิวน้ำถังกรอง → ไหลเองไม่ได้ · **ถ้าวัดแล้ววางถัง 3 ให้สูงกว่าผิวน้ำถังกรองได้** (ยอมยกถัง 1–2 สูงขึ้นตาม) → ใช้วาล์ว V3 แทนปั๊มได้ — ตัดสินหลังวัด (05 ข้อ 0.4) |
| D3 | **ฐานถัง 1–2 ต้องเรียบและแน่น** (บล็อกคอนกรีตวางเต็มแผ่น หรือขาตั้งถังน้ำสำเร็จรูป) | ถังเปล่าเบา แต่ตอนเต็ม น้ำ 1 ลิตร = 1 กก. → ถัง 100 ลิตรหนัก 100 กก. ฐานโยกได้ = ถังล้ม |
| D4 | **ถัง 3 เล็ก (~20 ลิตร) = กลไกความปลอดภัยหลัก** | ต่อให้ทุกอย่างพังพร้อมกัน น้ำจืดลงระบบได้ไม่เกินความจุถัง 3 (~14 ลิตรถึงท่อล้น) ≈ 3% ของระบบ 500 ลิตร → ความเค็มตกนิดเดียว ปูไม่ตาย |
| D5 | **ถัง 3 มีท่อล้นลงท่อระบายน้ำ (ไม่ใช่ลงระบบปู)** | ปั๊มค้าง/ลูกลอยเสีย → น้ำเกินไหลทิ้ง ไม่ท่วม ไม่ลงระบบ |
| D6 | **เส้นที่ใช้ปั๊ม (P3) มี "รูเบรกกาลักน้ำ" + ปลายสายลอยเหนือน้ำ (air gap)** · เส้นแรงโน้มถ่วงมีบอลวาล์วมือไว้ปิดฉุกเฉิน | ปั๊มดับแล้วน้ำต้องหยุดไหลทันที และน้ำในถังกรองต้องไหลย้อนกลับมาถัง 3 ไม่ได้ (ดู 01-glossary: กาลักน้ำ) |
| D7 | **ต่อลูกลอยแบบ fail-safe: สายขาด = ระบบเข้าใจว่า "หยุด"** | สายหลุด/ขั้วสนิมจะไม่ทำให้ปั๊มเดินค้าง |
| D8 | **ไม่ต่อไฟบ้าน 220V เองเลย** — ปั๊มลมเสียบปลั๊กตรงเปิดตลอด | มือใหม่ต่อ 220V ใกล้น้ำ = อันตรายถึงชีวิต; งาน DIY ทั้งหมดเป็นไฟ 12V/5V จากอะแดปเตอร์ |
| D9 | **วาล์ว/ปั๊มทำงานทีละตัวเสมอ** (V1, V2, P3 ห้ามพร้อมกัน) | กันน้ำที่ยังไม่ผสมโซดาไหลลงระบบ + ใช้อะแดปเตอร์เล็กลงได้ |
| D10 | **ไฟดับกลางรอบ → เปิดใหม่แล้วไม่ทำต่อเอง** (รอคนกด) | กันเติมซ้ำ/เติมเกิน |
| D11 | **ESP32 ทำงานเองได้ 100% ไม่พึ่งอินเทอร์เน็ต/เซิร์ฟเวอร์** | เน็ตหลุดหรือเว็บล่มต้องไม่ทำให้ปูตาย; เว็บฟาร์มใช้ดู/แจ้งเตือน (เฟส 4) |
| D12 | **ปล่อยน้ำลงถังกรอง ไม่ลงกล่องปูโดยตรง** แบบเป็นจังหวะ (เปิด 5 วิ / พัก 3 นาที) | น้ำจืดผสมกับน้ำทั้งระบบก่อนถึงตัวปู ค่าไม่กระชาก |
| D13 | **ปริมาณต่อรอบวัดด้วยลูกลอย ไม่ใช่นับเวลา** — ลูกลอยบนถัง 3 ติดที่ระดับ "5 ขัน" | อัตราไหลของปั๊มเปลี่ยนตามระดับน้ำ นับเวลาไม่แม่น |

### ประวัติการเปลี่ยนแนวทาง
- **2026-09-19 (รอบแรก):** Claude เปลี่ยนเป็นปั๊มทั้ง 3 ถัง เพราะเข้าใจผิดว่าถังพักต้องยกสูงเกิน 1 ม.
- **2026-09-19 (ผู้ใช้แก้):** ถังเบา ยกแค่นิดเดียว → **กลับไปใช้แรงโน้มถ่วง + โซลินอยด์สำหรับถัง 1–2 → ถัง 3** (D2) · ส่วนถัง 3 → ถังกรองใช้ปั๊มไว้ก่อนจนกว่าจะวัดความสูงหน้างาน (D2b)
- เฟส 1 **ไม่ต้องตักน้ำใส่ถัง 3 เอง** (ถังพักห่าง 3–4 ม. ถ้ายังต้องหิ้วน้ำ = ยังปวดหลังอยู่ดี) — วาล์วปล่อยน้ำจากถัง 1–2 ให้เอง

## 5. ลำดับเฟส

| เฟส | ทำอะไร | ได้อะไร | งบประมาณ | สถานะ |
|---|---|---|---|---|

| **1** | ถัง 3 + วาล์วปล่อยน้ำจากถัง 1/2 (กดปุ่มเลือกถังเอง) + หัวทราย + ปล่อยเข้าระบบช้า ๆ อัตโนมัติ + **ล็อกถังที่เพิ่งเติมประปา 24 ชม. (กดปุ่มค้าง)** + หน้าเว็บบนมือถือ; โซดายังใส่เองด้วยมือ (ยืนหย่อน 2 ช้อนลงถัง 3) | **เลิกแบก เลิกตัก เลิกคน เลิกตักผิดถัง** | ~4,000–5,500฿ (ลดได้ถ้ามีปั๊มลม/สว่านแล้ว) | ⬜ |

| 3 | โดสเบกกิ้งโซดาอัตโนมัติ (สารละลายเข้มข้น + ปั๊มรีดสาย) | ไม่ต้องอยู่บ้านก็เติมได้ | ~700–1,200฿ | ⬜ |

| 5 | เซนเซอร์ระดับน้ำในถังกรอง → เติมเองตามการระเหยจริง (หลักเดียวกับ ATO ตู้ปลาทะเล) | เลิกคิดเรื่องนี้ถาวร | ~300–800฿ | ⬜ |

## 7. กติกาการเขียนเอกสาร/อธิบายให้ผู้ใช้คนนี้

ผู้ใช้เป็น**มือใหม่มากทั้งงานช่างและ IoT** (ขอไว้ชัดเจน 2026-09-19):
- อุปกรณ์ทุกชิ้นต้องบอก **ประเภท + ชื่อรุ่น/ชื่อเฉพาะ + คำค้นหา (ไทยและอังกฤษ) + สเปกที่ต้องดู + ตัวที่ห้ามซื้อ**
- ศัพท์ใหม่ทุกคำให้เพิ่มลง [01-glossary.md](./01-glossary.md)
- ทุกขั้นตอนมี "วิธีเช็คว่าผ่าน" และ "ถ้าไม่ผ่านให้ดูอะไร"
- ขนาดท่อพูดเป็นทั้ง **หุน** และนิ้ว (ร้านวัสดุไทยพูดหุน)
