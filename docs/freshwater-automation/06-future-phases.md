# 🗺️ เฟส 2–5 (โครงร่าง) + การเชื่อมกับ express-farmland

> ยังไม่ต้องทำ — เขียนไว้ให้เห็นภาพรวมและให้การออกแบบเฟส 1 ไม่ปิดทางเฟสหลัง
> **กติกา:** เริ่มเฟสถัดไปได้เมื่อเฟสก่อนหน้าใช้จริงราบรื่น ≥ 2 สัปดาห์

## เฟส 2 — ระบบรู้เองว่าถังไหนเพิ่งเติมประปา

**ปัญหาที่เหลือจากเฟส 1:** ต้องจำกดปุ่มค้างทุกครั้งที่เติมประปา — ลืมกด = ระบบไม่รู้

**ของเพิ่ม:**
- อัลตราโซนิกกันน้ำ **A02YYUW** × 2 (ถัง 1, 2) — แนะนำตัวนี้มากกว่า JSN-SR04T เพราะติดใกล้น้ำได้ (JSN ต้องห่างผิวน้ำ ≥ 25 ซม.) · ส่งค่าแบบ UART → ต่อขา TX ของเซนเซอร์เข้า **GPIO34** และ **GPIO35** (ขา input-only ใช้รับ UART ได้ ไม่ชนกับรีเลย์)
- ฝาครอบกันแดดกันฝนให้เซนเซอร์

**ลอจิก:**
- ระดับน้ำพุ่งขึ้น > 5 ซม. ภายใน 10 นาที = มีคนเติมประปา → **ล็อกถังนั้นอัตโนมัติ** (ปุ่มกดค้างยังใช้ได้ เผื่อเซนเซอร์เสีย)
- เลือกถังเอง: ถังที่ไม่ล็อก + มีน้ำพอ + ถูกเติมมานานที่สุด → ปุ่มเขียว/น้ำเงินรวมเป็น "เริ่มรอบ" ปุ่มเดียวได้
- หน้าเว็บโชว์ % น้ำคงเหลือถัง 1, 2 + เตือน "ถังใกล้หมด ควรเติมประปา"
- ถ้าติดลูกลอย T1_LOW / T2_LOW ไว้ในเฟส 1 **เก็บไว้เป็นตัวสำรอง** (เซนเซอร์ 2 ชนิดต้องเห็นตรงกันถึงจะเปิดวาล์ว)

**ตั้งเวลาเติมอัตโนมัติ:** ยังไม่เปิดในเฟสนี้ (ยังต้องมีคนใส่โซดา) — ถ้าอยากได้ก่อนเฟส 3 ให้ทำแบบ "ถึงเวลา → ปี๊บเรียกให้ใส่โซดา → รอกดยืนยัน"

**(ทางเลือก) ให้ระบบเติมประปาลงถัง 1, 2 เอง:** โซลินอยด์วาล์ว 12V แบบ **pilot operated (ตัวพลาสติกราคาถูกใช้ได้เพราะท่อประปามีแรงดัน)** ต่อที่ก๊อกประปา + หยุดด้วยอัลตราโซนิก + หมดเวลา + **ต้องเจาะท่อล้นให้ถัง 1, 2 ก่อน** (ถังใหญ่ ถ้าล้นคือน้ำท่วม) → ระบบรู้เวลาเติมแน่นอน ไม่ต้องเดา

งบประมาณ ~800–1,500฿ (ไม่รวมโซลินอยด์)

## เฟส 3 — โดสเบกกิ้งโซดาอัตโนมัติ

**หลักการ:** ละลายโซดาเป็น "สารละลายแม่" ไว้ล่วงหน้า แล้วให้ปั๊มรีดสายปล่อยตามปริมาณ (ไม่ป้อนผง — ผงโซดาดูดความชื้นจับเป็นก้อน เครื่องป้อนผงตันภายในไม่กี่วัน)

**ของเพิ่ม:**
- ปั๊มรีดสาย 12V (`Kamoer NKP 12V` หรือ `peristaltic pump 12V`) → รีเลย์ CH4 (**GPIO19** เตรียมไว้แล้ว)
- ถังทึบแสงมีฝา 10–20 ลิตร สำหรับสารละลายแม่
- ลูกลอย 1 ตัวในถังสารละลาย (เตือน "โซดาใกล้หมด") → **GPIO4** (input pull-up)

**สูตร:**
- เบกกิ้งโซดาละลายได้สูงสุด ~96 กรัม/ลิตร ที่ 20°C → ผสม **50–60 กรัม/ลิตร** (ไม่ตกผลึกตอนอากาศเย็น)
- 2 ช้อน ≈ 30 กรัม (**ชั่งจริง 1 ครั้งด้วยตาชั่งครัว** ช้อนพูน/ปาดต่างกันมาก) → ใช้สารละลาย ~500–600 มล. ต่อรอบ
- ผสมใหม่ทุก 1–2 สัปดาห์ (ตั้งทิ้งนานค่าเปลี่ยน)

**ลอจิก:**
- คาลิเบรตปั๊ม: เปิด 60 วิ ลงถ้วยตวง → ได้ มล./วิ → เก็บในตั้งค่า
- โดสตอน **เริ่มเติมถัง 3** (น้ำที่ไหลเข้า + หัวทรายช่วยผสม) · ถ้าลูกลอยถังสารละลายบอกหมด → ไม่เริ่มรอบ + เตือน
- เปลี่ยนสายยางปั๊มรีดสายทุก 3–6 เดือน (สายสึก ปริมาณเพี้ยน)
- **เปิดตั้งเวลาเติมอัตโนมัติได้แล้วในเฟสนี้** (ไม่ต้องมีคนอยู่บ้าน)

**อนาคต:** ปรับปริมาณโซดาตามค่าอัลคาไลน์ที่วัดล่าสุดในแอปฟาร์ม (ใช้ `DosingCalibration.effectPerUnit` ที่มีอยู่แล้ว) — ต้องทำเฟส 4 ก่อน

งบประมาณ ~700–1,200฿

## เฟส 4 — เชื่อมกับเว็บ express-farmland

**หลัก:** ESP32 ยังตัดสินใจเองทั้งหมด (ข้อ D11 ใน README) — เว็บมีไว้ **บันทึก / แจ้งเตือน / ดูจากนอกบ้าน**

### ของที่มีอยู่แล้วในระบบ (เช็ค 2026-09-19)
- `ReminderType.FRESHWATER_TOPUP` ใน `prisma/schema.prisma` (งานเติมน้ำจืด)
- `TriggerEvent.AFTER_FRESHWATER` + `reminder.service.fireEvent(event, systemId)` → สร้างงาน "วัดค่าน้ำหลังเติมน้ำจืด" จากกฎใน seed
- ระบบเมลสรุปงานค้าง (`notifyPendingDigest`) + WebSocket (`lib/realtime.ts`)

### ที่ต้องเพิ่ม (ร่าง — ออกแบบละเอียดตอนเริ่มเฟส)
- **model `Device`** (`systemId`, `name`, `apiKeyHash` แบบเดียวกับ `RefreshToken` คือเก็บ sha256, `lastSeenAt`, `firmwareVersion`)
- **model `FreshwaterCycle`** (`systemId`, `deviceId`, `sourceTank`, `startedAt`, `finishedAt`, `result` = DONE/ERROR/STOPPED/INTERRUPTED, `errorCode`, `fillSec`, `releaseSec`)
- **route `/api/devices/*`** mount ก่อน `requireAuth` (แบบเดียวกับ `/public`, `/scheduler`) ยืนยันตัวด้วย header `x-device-key`
  - `POST /api/devices/events` — ESP32 ส่งเหตุการณ์เป็นชุด (เก็บคิวไว้ในเครื่องตอนเน็ตหลุด แล้วส่งย้อนหลัง)
  - `POST /api/devices/heartbeat` — ทุก 5 นาที
- **hook เมื่อรอบจบสำเร็จ:** ปิด Task `FRESHWATER_TOPUP` ที่ค้าง (DONE + `linkType:'FreshwaterCycle'`) → `fireEvent('AFTER_FRESHWATER', systemId)` → ได้งาน "วัดค่าน้ำ" อัตโนมัติ
- **hook เมื่อ error / กล่องเงียบ:** สร้าง Task แจ้งเหตุ → เข้าเมลสรุปเดิม · `scheduler.tick` เช็ค `lastSeenAt` เกิน 30 นาที = "กล่องควบคุมขาดการติดต่อ"
- **หน้าเว็บใหม่ (farmland-web):** "เติมน้ำอัตโนมัติ" — สถานะ, ประวัติรอบ, ถังไหนล็อกอยู่, สถิติ (เติมกี่ลิตร/สัปดาห์ = อัตราระเหย)
- **สั่งงานจากนอกบ้าน (ทำทีหลัง):** ESP32 ถามคำสั่งค้างทุก 30 วิ (polling ง่ายกว่าเปิด WebSocket บนอุปกรณ์) · ต้องยืนยัน 2 ชั้น

### ข้อควรระวัง
- ESP32 ยิง HTTPS ไป `api-farmland.family-sivarom.com` ต้องฝังใบรับรองราก (Let's Encrypt `ISRG Root X1`) — **ห้ามใช้ `setInsecure()` ในของจริง**
- API key ต่ออุปกรณ์ เพิกถอนได้ · ห้ามใช้ JWT ของผู้ใช้ฝังในเครื่อง

## เฟส 5 — เติมตามระดับน้ำจริงในถังกรอง

**หลักการ:** เหมือนระบบ **ATO** ของตู้ปลาทะเล — น้ำในถังกรองต่ำกว่าเส้น = น้ำระเหยไปแล้ว → เริ่มรอบเติมเอง · อากาศร้อนเติมถี่ อากาศเย็นเติมห่าง อัตโนมัติ

**ของเพิ่ม:**
- เซนเซอร์ระดับน้ำแบบแสง (`optical liquid level sensor`) **2 ตัว** ในถังกรอง: ตัวที่ 1 = "ต่ำ ควรเติม" · ตัวที่ 2 (สูงกว่า) = "สูงเกิน ห้ามเติมเด็ดขาด" (ตัวสำรองกันพลาด)
- DS18B20 วัดอุณหภูมิน้ำ (แถม ส่งเข้าแอปได้)
- (ทางเลือก) เซนเซอร์ EC/ความเค็ม ไว้เตือนเฉย ๆ ไม่ใช้สั่งงาน

**ลอจิก:** ต่ำค้าง ≥ 10 นาที (กันคลื่น) → เริ่มรอบ · เพดาน **ไม่เกิน N รอบ/วัน** · เซนเซอร์ 2 ตัวขัดกัน → หยุด + เตือน

**ทางลัด:** มีชุด ATO สำเร็จรูปขาย (ค้น `ATO ตู้ปลาทะเล`) — อาจซื้อมาใช้เป็นตัวสั่งแทนการทำเซนเซอร์เอง

งบประมาณ ~300–800฿

## ทางเลือกที่พิจารณาแล้วไม่เลือก (เผื่อเปลี่ยนใจ)

| ทางเลือก | ทำไมยังไม่เลือก |
|---|---|
| ESPHome + Home Assistant | ง่ายกว่า (เขียนแค่ YAML) แต่ต้องมีเครื่องรัน Home Assistant แยก และแยกจากเว็บฟาร์มที่มีอยู่ |
| ปั๊มทุกขา (ถัง 1, 2, 3 ใช้ปั๊มหมด) | ใช้ได้ไม่ว่าถังจะสูงแค่ไหน แต่มีปั๊มให้เสีย 3 ตัว + ต้องกันปั๊มเดินแห้ง + รูเบรกกาลักน้ำทุกเส้น · ผู้ใช้เลือกแรงโน้มถ่วงสำหรับถัง 1–2 (2026-09-19) — **ยังเป็นทางถอยถ้าโซลินอยด์ไม่ผ่านการทดสอบหัวน้ำต่ำ** |
| มอเตอร์บอลวาล์ว | เปิดได้ที่แรงดันศูนย์และรูกว้าง แต่ไฟดับแล้วค้างตำแหน่งเดิม (ค้างเปิด = น้ำไหลไม่หยุด) |
| ปลั๊ก WiFi (Tuya/Sonoff) ตั้งเวลาเปิดปั๊ม | ไม่มีเซนเซอร์ ไม่รู้ว่าน้ำเต็ม/หมด = เสี่ยงล้นหรือปั๊มแห้ง |
| ชุด ATO สำเร็จรูปอย่างเดียว | ไม่มีเรื่องเลือกถังที่พักครบ + ผสมโซดา (แต่ใช้ร่วมในเฟส 5 ได้) |
