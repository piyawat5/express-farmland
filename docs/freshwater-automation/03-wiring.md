# 🔌 ผังขา ผังสายไฟ ผังท่อน้ำ

> ในผังรูปภาพใช้ตัวอักษรอังกฤษ (ภาษาไทยทำให้เส้นเบี้ยวในกล่องโค้ด) — มีคำอธิบายภาษาไทยใต้ผังทุกรูป
> ⚠️ **ปรับตามของจริงที่ซื้อมา** ก่อนต่อ — ถ้ารุ่นต่างจากแผนให้บอก Claude แก้ไฟล์นี้ก่อน
> **แนวทางปัจจุบัน (ผู้ใช้ยืนยัน 2026-09-19):** ถัง 1/2 → ถัง 3 ไหลเองผ่านโซลินอยด์ **V1, V2** · ถัง 3 → ถังกรองใช้ปั๊ม **P3** (หรือวาล์ว V3 ถ้าวัดแล้วความสูงพอ)

## 0. กฎความปลอดภัยก่อนต่อสาย (อ่านทุกครั้ง)

1. **ถอดปลั๊กอะแดปเตอร์ 12V ทุกครั้งก่อนต่อ/ถอดสาย** — ต่อเสร็จ ตรวจตามตาราง แล้วค่อยเสียบ
2. **ตอนเสียบ USB เข้าคอมเพื่ออัปโหลดโค้ด ให้ถอดปลั๊กอะแดปเตอร์ 12V ก่อน** (กันไฟ 2 ทางชนกัน)
3. **ไม่มีงานไฟบ้าน 220V ในโปรเจกต์นี้เลย** — ปั๊มลมเสียบปลั๊กผนังตรง ๆ, อะแดปเตอร์เสียบปลั๊กผนังตรง ๆ · ถ้าวันหนึ่งอยากคุมอุปกรณ์ 220V ให้ใช้ "ปลั๊ก WiFi สำเร็จรูป" ไม่ต่อรีเลย์เอง
4. ขั้วบวก (+) ใช้สายสีแดง/สีน้ำตาล · ขั้วลบ (GND, −) ใช้สายสีดำ/สีน้ำเงิน **ตลอดทั้งกล่อง** — สลับขั้วเมื่อไรอุปกรณ์พังเมื่อนั้น
5. ขันสายเข้าขั้วสกรูแล้ว **ดึงเบา ๆ ทุกเส้น** ต้องไม่หลุด

## 1. ผังขา ESP32 (Pin map) — เฟส 0 + เฟส 1

| GPIO | ต่อกับ | ชนิด | อ่านได้ LOW แปลว่า | อ่านได้ HIGH แปลว่า |
|---|---|---|---|---|
| 16 | รีเลย์ IN1 → **โซลินอยด์ V1 (ถัง 1 → ถัง 3)** | output | วาล์วปิด | วาล์วเปิด |
| 17 | รีเลย์ IN2 → **โซลินอยด์ V2 (ถัง 2 → ถัง 3)** | output | วาล์วปิด | วาล์วเปิด |
| 18 | รีเลย์ IN3 → **ปั๊ม P3 (ถัง 3 → ถังกรอง)** หรือวาล์ว V3 | output | ดับ/ปิด | เดิน/เปิด |
| 19 | รีเลย์ IN4 → สำรอง (เฟส 3: ปั๊มโดสโซดา) | output | — | — |
| 32 | ลูกลอย **T3_HIGH** (ถัง 3 ระดับบน) | input pull-up | ยังไม่เต็ม | **เต็ม** (หรือสายขาด) |
| 33 | ลูกลอย **T3_LOW** (ถัง 3 ระดับล่าง) | input pull-up | มีน้ำ | **หมด** (หรือสายขาด) |
| 25 | ลูกลอย T1_LOW (ถัง 1 ใกล้หมด) — **ไม่บังคับ** | input pull-up | มีน้ำ | หมด (หรือสายขาด/ไม่ได้ติด) |
| 26 | ลูกลอย T2_LOW (ถัง 2 ใกล้หมด) — **ไม่บังคับ** | input pull-up | มีน้ำ | หมด (หรือสายขาด/ไม่ได้ติด) |
| 27 | ปุ่มเขียว **B1** "ถัง 1" | input pull-up | กดอยู่ | ปล่อย |
| 14 | ปุ่มน้ำเงิน **B2** "ถัง 2" | input pull-up | กดอยู่ | ปล่อย |
| 13 | ปุ่มแดง **B3** "หยุด" | input pull-up | กดอยู่ | ปล่อย |
| 23 | บัซเซอร์ ขา I/O | output | (ขึ้นกับรุ่น — ตั้งในเฟิร์มแวร์) | |
| 2 | ไฟ LED สีฟ้าบนบอร์ด (สถานะ) | output | | |

- ทุกเซนเซอร์จัดให้ "สายขาด = อ่านได้ HIGH = ความหมายที่ทำให้ระบบหยุด" (fail-safe) — ดูข้อ 5
- ลูกลอย T1_LOW / T2_LOW **ไม่บังคับ** เพราะวาล์วแรงโน้มถ่วงไม่มีปัญหาเดินแห้งแบบปั๊ม (ถังหมด = น้ำหยุดไหล → เฟิร์มแวร์จับได้จากการเติมหมดเวลา) · ถ้าไม่ติด เฟิร์มแวร์ต้องตั้งให้ "ไม่ใช้" ไม่งั้นจะอ่านเป็น "หมด" ตลอด

**ขาที่ห้ามใช้ (สำหรับ Claude ตอนแก้ผัง):** GPIO 0, 5, 12, 15 (ขา strapping มีผลตอนบูต) · 6–11 (ต่อกับหน่วยความจำแฟลช) · 1, 3 (TX/RX ใช้อัปโหลด) · 34–39 เป็น input อย่างเดียวและ **ไม่มี pull-up ในตัว** (เฟส 2 จะใช้ 34, 35 รับค่าเซนเซอร์อัลตราโซนิก)

## 3. เฟส 1 — ผังไฟ (ภาพรวม)

```
 WALL 220V --[ ADAPTER 12V 5A ]==plug==> [ DC JACK IN ]
                                            (+)     (-)
                                             |       |
                                        [ FUSE 5A ]  |
                                             |       |
                        +--------------------+       +--------------------+
                        |  BUS +12V (Wago 221-415)   |  BUS GND-PWR (Wago 221-415)
                        |                            |
      Mini560 IN+  <----+                            +----> Mini560 IN-
      RELAY CH1 COM <---+                            +----> VALVE V1 coil pin 2
      RELAY CH2 COM <---+                            +----> VALVE V2 coil pin 2
      RELAY CH3 COM <---+                            +----> PUMP P3 (-)

      RELAY CH1 NO -----------------------------------> VALVE V1 coil pin 1   (+ diode)
      RELAY CH2 NO -----------------------------------> VALVE V2 coil pin 1   (+ diode)
      RELAY CH3 NO -----------------------------------> PUMP P3 (+)

      Mini560 OUT+ (5V) --> BUS 5V (Wago 221-413) --> ESP32 VIN, RELAY VCC
      Mini560 OUT- -------> BUS GND-SIG (Wago 221-415) --> ESP32 GND, RELAY GND,
                                                            float/button GND wires
```

**คำอธิบาย:** อะแดปเตอร์ → แจ็คขาเข้า → ฟิวส์ → "บัส +12V" แจกไฟไปตัวลดไฟ 5V และขา COM ของรีเลย์ 3 ช่อง · ขา NO ของช่อง 1, 2 ไปที่คอยล์วาล์ว V1, V2 · ช่อง 3 ไปปั๊ม P3 · ขั้วลบทุกตัวกลับไป "บัส GND-PWR" · ตัวลดไฟ 5V เลี้ยง ESP32 + แผงรีเลย์

### 3.1 ต่อคอยล์วาล์ว + ไดโอด (ทำในปลั๊ก DIN ที่หัววาล์ว)

```
   from RELAY NO (+12V when ON) ----+-------------> DIN pin 1
                                    |
                               [ 1N4007 ]  stripe side (|) toward pin 1 / +
                                    |
   from BUS GND-PWR (-) ------------+-------------> DIN pin 2

   (DIN earth pin = not used)
```

**คำอธิบาย:** เปิดฝาปลั๊ก DIN ที่เสียบบนหัวโซลินอยด์ → ข้างในมีขั้วสกรู 1, 2 และขั้วกราวด์ (ไม่ใช้) · ขันสาย + เข้าขั้ว 1, สาย − เข้าขั้ว 2 · ขันขาไดโอดคร่อมขั้ว 1 กับ 2 โดย **ด้านแถบสีเงินอยู่ขั้ว 1 (+)** · ใส่ไดโอดกลับด้าน = ลัดวงจร ฟิวส์ขาด (ไม่มีอะไรไหม้ แต่ต้องแก้แล้วเปลี่ยนฟิวส์)

## 5. ติดลูกลอยแบบ fail-safe (สำคัญ)

ลูกลอย ZP4510 กลับหัวได้ → เลือกได้ว่า "น้ำถึงแล้ววงจรต่อ" หรือ "น้ำถึงแล้ววงจรตัด" · เราจัดให้ **สายขาด = ระบบหยุด** เสมอ:

| ลูกลอย | ติดให้เป็นแบบนี้ | ESP32 อ่าน | ถ้าสายขาด |
|---|---|---|---|
| T3_LOW (และ T1_LOW, T2_LOW ถ้าติด) | **น้ำท่วมลูกลอย = ต่อ (ปี๊บ)** · น้ำลดต่ำกว่าลูกลอย = ตัด | LOW = มีน้ำ | อ่านได้ "หมด" → ไม่ปล่อยน้ำ ✓ |
| T3_HIGH | **น้ำยังไม่ถึง = ต่อ (ปี๊บ)** · น้ำถึงลูกลอย = ตัด | HIGH = เต็ม | อ่านได้ "เต็ม" → ไม่เปิดวาล์วเติม ✓ |

**วิธีตั้งก่อนติด (ทำในถังน้ำ):** มัลติมิเตอร์โหมดปี๊บ แตะ 2 สายลูกลอย → จุ่มลูกลอยลงน้ำ/ยกขึ้น → ถ้าพฤติกรรมไม่ตรงตาราง ให้ถอดคลิปล่าง กลับหัวลูกลอย ใส่คลิปคืน แล้วทดสอบใหม่ → เขียนป้าย "H" / "L" ติดสายไว้

```
               |  concrete  |                               |  air gap
               |  blocks /  |                               v
               |  stand     |          RIM of TANK 3 --- +------------+
               |            |                            | ~~~~~~~~~~ |
   FLOOR ------+------------+----------------------------+------------+------

   RULE 1:  outlet of TANK 1/2  >=  RIM of TANK 3  + 5 cm
```

**คำอธิบาย:** น้ำไหลเองได้แค่ "ลง" · **รูทางออกของถัง 1/2 (ใกล้ก้นถัง) ต้องสูงกว่าขอบบนของถัง 3 อย่างน้อย 5 ซม.** → น้ำไหลได้จนถังพักเกือบหมด และไหลเข้าถัง 3 จากด้านบน · ถัง 3 ยิ่งเตี้ย ถัง 1/2 ยิ่งยกน้อย (ถัง 3 สูง 25 ซม. → รูทางออกสูง ~30 ซม. → ยกถัง 1/2 ราว 25–30 ซม.)

**กฎข้อ 2 (ถัง 3 → ถังกรอง):** ถ้าอยากให้ไหลเองด้วยวาล์ว V3 ต้องมี **ก้นถัง 3 สูงกว่าผิวน้ำในถังกรอง** → ถัง 3 ต้องยกขึ้น → ถัง 1/2 ต้องยกสูงขึ้นอีกตามกฎข้อ 1 · ถ้าทำไม่ได้ (ปกติเป็นแบบนี้) = ใช้ **ปั๊ม P3**

### 6.1 ภาพรวมการไหล

```
 [TANK 1 on base] --ball valve--Y--[V1]--hose ~5 m--\
                                                     >--> [TANK 3, low box] --P3 (pulsed)--> hose --> [FILTER / SUMP]
 [TANK 2 on base] --ball valve--Y--[V2]--hose ~5 m--/          |
                                                               +--> OVERFLOW 3/4" hose --> DRAIN  (NEVER to crabs)

 [AIR PUMP, wall plug, always ON] --airline--> check valve --> air stone in TANK 3
                                                           (+ TANK 1, TANK 2 recommended)
```

- ถัง 3 **วางบนพื้น** ชิดระบบปู · ปั๊ม P3 จุ่มที่ก้นถัง 3
- น้ำจากถัง 3 ลง **ถังกรอง** (ไม่ใช่กล่องปู) — ช่องไหนให้ผู้ใช้ยืนยันหน้างาน (ช่องที่ปั๊มหลักดูดไปจะผสมเร็วที่สุด)

### 6.2 ชุดวาล์วที่ถัง 1 และถัง 2

```
   inside TANK 1 | outside
                 |
     ~~~~~~~~    |
     water       |
   ==[ bulkhead ]==[ BALL VALVE ]==[nipple]==[ Y-STRAINER ]==[nipple]==[ SOLENOID V1 ]==[ hose barb ]--> hose to TANK 3
     3-5 cm      |     manual           ->         arrow ->                 arrow ->
     above floor |     shut-off                                          (DIN plug on top)
     of tank     |
```

**คำอธิบาย:** เจาะรูข้างถัง **สูงจากก้นถังด้านใน 3–5 ซม.** (ไม่ดูดตะกอนก้นถัง) → ใส่ข้อต่อถังน้ำ 4 หุน → บอลวาล์ว (ปิดด้วยมือได้เสมอ) → วายสเตรนเนอร์ (กรองเศษ) → โซลินอยด์ → หางปลาไหล → สายยางไปถัง 3
- **ลูกศรบนวายสเตรนเนอร์และโซลินอยด์ต้องชี้ออกจากถัง** (ทิศน้ำไหล)
- พันเทปพันเกลียวทุกเกลียวนอก 5–8 รอบ ตามเข็มนาฬิกา · ใช้ประแจ 2 อัน (จับตัวหนึ่ง หมุนอีกตัว) **อย่าให้ข้อต่อถังหมุนตาม** ไม่งั้นรั่ว
- ชุดวาล์วหนัก → **หาอะไรรองใต้โซลินอยด์** (อิฐ/ไม้) อย่าให้น้ำหนักห้อยอยู่ที่ผนังถัง
- หัววาล์ว (ปลั๊ก DIN) หันขึ้นด้านบน รูสายไฟชี้ลง

### 6.3 ระดับในถัง 3 (มองจากด้านข้าง)

```
  RIM of tank 3        ----------------   (top)
                                            ^ at least 2 cm
  OVERFLOW hole        ----------------   --> 3/4" hose to DRAIN
                                            ^ at least 3 cm
  hose ends from V1/V2 (hang ABOVE the overflow level = air gap)
  T3_HIGH float        ----------------   = "5 khan" mark -> filling STOPS here
            ...   one top-up of water  ...
  T3_LOW float         ----------------   = releasing STOPS here (pump never dry)
                                            ^ at least 3 cm
  top of pump P3       ----------------
  BOTTOM of tank 3
```

**คำอธิบาย:** ลูกลอยบน = จุดหยุดเติม (ตั้งตรงขีด "5 ขัน" ที่ตวงจริง) · ท่อล้นสูงกว่าลูกลอยบนอย่างน้อย 3 ซม. · ปลายสายจาก V1/V2 แขวนเหนือระดับท่อล้น · ลูกลอยล่าง = จุดหยุดปล่อย สูงกว่ายอดปั๊ม P3 อย่างน้อย 3 ซม. (ปั๊มจะได้จมน้ำตลอด)
- ถัง 3 เตี้ย ระยะแต่ละขั้นจะแคบ — ตัวอย่างกล่องพื้น 30×40 ซม. สูง 25 ซม.: ปั๊มสูง ~6 ซม. → L ~9 ซม. → 7.5 ลิตรทำให้น้ำขึ้น ~6 ซม. → H ~15 ซม. → ท่อล้น ~18 ซม. → ขอบ 25 ซม. ✓

### 6.4 เส้นปั๊ม P3: รูเบรกกาลักน้ำ + ช่องว่างอากาศ

```
             hose goes up, over the rim, to the FILTER / SUMP
                    +-------------------------------------+
                    |                                     |
   RIM  ============|========   <- tie hose to the rim    |
                    o           <- 3 mm hole: inside       v   hose end hangs
                    |              TANK 3, above overflow      >= 3 cm ABOVE
   water ~~~~~~~~~~~|~~~~~~~~                                  sump water (air gap)
                 [ P3 ]   (on the bottom of TANK 3)        ~~~~~~~~~~~~~~~~~~
```

**คำอธิบาย:** ถัง 3 อยู่ต่ำกว่าถังกรอง → ถ้าปลายสายจุ่มอยู่ในน้ำถังกรอง **น้ำจากระบบปูจะไหลย้อนกลับมาถัง 3 แล้วออกท่อล้นทิ้งได้ (ระบบปูน้ำลด!)** → ป้องกัน 2 ชั้น: (1) **ปลายสายต้องแขวนลอยเหนือผิวน้ำถังกรอง ≥ 3 ซม. เสมอ** (2) เจาะรู 3 มม. ที่สายยางช่วงที่อยู่ในถัง 3 เหนือระดับท่อล้น — ปั๊มเดินมีน้ำพุ่งจากรูลงถัง 3 นิดหน่อย (ปกติ) ปั๊มดับอากาศเข้ารูตัดสายน้ำทันที

### 6.5 เสาเซนเซอร์ (ใส่ลูกลอยโดยไม่ต้องเจาะถังใต้น้ำ)

```
       float cable exits here (top of pole is open, stays dry)
                 |
   RIM =====[tie]|[tie]=====    <- 2 cable ties through 2 small holes near the rim
                 ||
                 ||   PVC pipe 3/4" (6 hun), cut to length
                 ||   (float cable runs INSIDE the pipe)
                 ||
             +---++---+
             | end cap|         <- 3/4" end cap, 10 mm hole in the centre,
             +---++---+            float stem screwed through, nut on the inside
                 ||  <- stem (M10), pointing DOWN
                (##) <- float slides up/down on the stem
                 ==  <- clip
```

**คำอธิบาย:** ลูกลอยห้อยอยู่ใต้ปลายเสา · ระดับที่ลูกลอยทำงาน ≈ ตำแหน่งลูกลอย · **ปรับระดับ = คลายเคเบิลไทร์ เลื่อนเสาขึ้น-ลง** · ใช้ 2 เสาในถัง 3 (H, L) · ถัง 1, 2 อีกถังละ 1 เสา **ถ้าเลือกติด**
